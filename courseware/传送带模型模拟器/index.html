      使用说明

      课堂演示：左侧选经典场景 → 空格 播放。默认在共速、速度为零、离开、碰撞等关键时刻自动暂停，右上角弹出讲解；再按空格继续。速度可调到 0.25× 慢放。

      看懂摩擦力方向：紫色虚线箭头是物块相对传送带的滑动方向，滑动摩擦力 f 与它相反；相对静止时 f 为静摩擦力，大小由 m(g sinθ + a带) 决定。

      图像：每张图可在标题处切换 7 种图像；点击图像跳到该时刻（靠近关键时刻会自动吸附）；点击图例可隐藏某条线；“PNG”按钮保存图片用于命题。

      放物块：点击带面即在该处放一个物块（初速取左侧“新物块初速”）；t=0 时可拖动物块调整位置。

      快捷键：空格 播放/暂停　←→ 逐帧（0.02 s）　Shift+←→ 跳到上/下一个关键时刻　Home 回到 0

      模型约定：物块视为质点（以中心到达端点为离开）；各物块与带间 μ 相同，最大静摩擦力等于滑动摩擦力；带的运动由电动机保证，不受物块影响；传送带总长按 2L 计（忽略滚筒弧长），用于计算痕迹是否绕满一圈。

      计算方法：事件驱动的分段解析解——每段加速度恒定，按“共速、到达端点、碰撞、带变速结束”求出精确分段时刻；热量、电动机做功均按解析积分独立计算，再用 W电 = ΔEk + ΔEp + Q + 碰撞损耗 校验（差值只剩浮点舍入误差）。
