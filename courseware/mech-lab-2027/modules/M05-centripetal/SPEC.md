## 1. 教学目标（对应高考考点）
1. 理解向心力的概念与猜想：物体做匀速圆周运动所需的向心力 `F_n = m ω² r` 与质量 `m`、角速度 `ω`、转动半径 `r` 有关。
2. 掌握**控制变量法**的实验设计：分别控制其中两个量不变，定量探究 `F` 与 `m`、`F` 与 `r`、`F` 与 `ω²` 的正比关系。
3. 掌握**装置 A（教材向心力演示器）**结构、原理与读数方法：
   - **皮带变速塔轮原理**：皮带不打滑时两侧边缘线速度相等（`v_L = v_R`），故 `ω_L / ω_R = R_R / R_L`（角速度与塔轮半径成**反比**，切勿与半径比弄反）；
   - **转换法**：两套弹簧套筒将不可见的向心力大小转换为黑白等分标尺向上露出的格数（`F ∝ n_露`）；
   - **长槽与短槽**：长槽内侧与短槽半径均为 `r`（`6.0 cm`），长槽外侧为 `2r`（`12.0 cm`）；B 球质量 `2m`、A 球 `m`、C 球 `3m`。
4. 掌握**装置 B（数字化实验：力传感器 + 光电门）**原理与数据处理：
   - 10 分度游标卡尺测遮光片宽度 `d`（不估读，保留到 `0.1 mm`）；
   - 光电门测线速度 `v = d / Δt`，向心力 `F = m v² / r = m d² / (r Δt²)`；
   - **化曲为直**：将非线性 `F - ω` 曲线转化为过原点直线 `F - ω²` 或 `F - 1/Δt²`，并能分析存在静摩擦时 `F - ω²` 直线的正横截距 `ω₀² = f_静 / (m r)` 与不变斜率 `k = m r`。
5. 掌握高考创新变式：2024 海南卷圆盘小圆柱 `r = (D − d) / 2`、2025 北京卷纸带测圆周切向加速度与向心加速度 `a_n = v² / R`、圆锥摆验证向心力公式（质量可消去）。

## 2. 物理模型（`ML.centrip` in `scene.js`）

### 2.1 装置 A：教材向心力演示器
| 参数 | 默认 | 说明 |
|---|---|---|
| 塔轮三档半径 `PULLEY_RADII` | `[0.020, 0.040, 0.060]` m | 对应 `2 cm / 4 cm / 6 cm`（档位索引 `0, 1, 2`） |
| 小球规格 `BALLS` | `al: 0.020 kg` / `steel: 0.040 kg` / `copper: 0.060 kg` | 质量比 `1 : 2 : 3` |
| 槽位半径 | 左内/右短：`0.060 m`；左外：`0.120 m` | 半径比 `1 : 2` |
| 标尺灵敏度 `kScale` | `0.0432 N/div` | 基准 `m=0.020, r=0.060, ω=6.0` 时 `F=0.0432 N = 1.00` 格 |
| 手柄角速度 `omegaCrank` | `6.0 rad/s` | 右侧手柄直接驱动右轮 `ω_R = ω_crank`，皮带带动左轮 |

- 无打滑传动：`ω_L = ω_R · (R_R / R_L)`，`F = m ω² r`，露格 `div = F / kScale`。
- 误差模型参数化：
  - `E1`：未控制变量（探 `F-ω` 时错改 `r` 或 `m`）；
  - `E2`：塔轮半径比与角速度比弄反（`R_L:R_R = 2:1 ⇒ ω_L:ω_R = 1:2, F_L:F_R = 1:4`）；
  - `E3`：皮带松弛打滑（从动轮滑移率 `slip = 0.18` ⇒ `ω_从 = ω_理 (1 − 0.18)`，向心力偏小 `1 − 0.82² = 32.76%`）；
  - `E4`：摇动手柄忽快忽慢（转速 `±22%` 波动，标尺示数跳动、标准差显著增大）；
  - `E5`：标尺套筒未调零（零偏 `+0.60` 格）+ 套筒静摩擦滞回（`0.25` 格），破坏正比且出现升降滞回差。

### 2.2 装置 B：力传感器 + 光电门
| 参数 | 默认 | 范围 / 说明 |
|---|---|---|
| 滑块质量 `m` | `0.100 kg` | `0.050 / 0.100 / 0.150 kg` |
| 转动半径 `r` | `0.150 m` | `0.080 .. 0.200 m` |
| 遮光条宽度 `d` | `0.0100 m`（`10.0 mm`） | 可嵌用 `GaugeBench` 10 分度游标卡尺读数 |
| 角速度 `ω` | `6.0 rad/s` | `2.0 .. 12.0 rad/s` |
| 导轨静摩擦 `fStatic` | `0.12 N`（`E6` 开启时） | `F_sensor = max(0, m ω² r − fStatic)` |

- 挡光时间 `Δt = d / (ω r)`（真实模式含微小计数抖动）。
- 存在静摩擦（`E6`）时：`F - ω²` 直线斜率仍为精确的 `m r`，横截距为 `ω₀² = fStatic / (m r)`。
- 辅助函数：`hainan2024Disk(D, d, m, N, t)` 返回 `{ T, w, r, F }`；`fitSensor(rows, xKey)` 支持 `'omega2' | 'invDt2' | 'm' | 'r'`。

## 4. 校验（`verify.mjs`）
1. 装置 A 控制变量比值（`2.000`、`2.000`、`0.2500`、`1/9`）及组合比值 `16.00` 误差 `< 0.1%`。
2. 皮带打滑 `slip = 0.18` 向心力偏小 `32.76%`；转速不稳显著增大读数标准差；零偏与套筒滞回破环正比。
3. 装置 B `F - ω²` 与 `F - 1/Δt²` 线性拟合误差 `< 0.1%`；`E6` 静摩擦产生正横截距 `fStatic / (m r)` 且斜率保持 `m r`。
4. `hainan2024Disk` 复现 `ω ≈ 1.0 rad/s`、`F ≈ 6.06×10⁻³ N`。
5. `content.json` 与 `questions.json` 全量自动核验。
