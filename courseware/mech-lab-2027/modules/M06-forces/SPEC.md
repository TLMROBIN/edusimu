## 1. 教学目标（对应高考考点）
1. 理解并掌握**等效替代法**：用两只弹簧测力计互成角度拉橡皮条与用一只弹簧测力计拉橡皮条时，必须将橡皮条的结点拉到**同一位置 `O`**，使橡皮条的形变大小和方向完全相同。
2. 明确区分**理论值 `F`** 与**实际值 `F'`**（或题设对应记号）：
   - 按平行四边形定则作出的对角线为理论合力 `F`，受读数、描点、作图误差影响可能略有偏斜；
   - 用一只测力计单独将结点拉到 `O` 点时的拉力 `F'` 为实际合力，因直接与橡皮条弹力平衡，其方向**一定沿橡皮条伸长方向 `AO`**。
3. 掌握**弹簧测力计的校准与读数**：水平对拉校验两表读数一致性并调零；`0–5 N`（分度值 `0.1 N`）测力计须估读到 `0.01 N`。
4. 掌握**力的图示作图法**与实验操作规范：统一标度（如 `1 cm = 1.0 N`）、测力计与细绳套和木板平面平行、细绳套适当长、描点离 `O` 适当远、两分力夹角适宜（`60°–120°`）、同次实验 `O` 点固定而不同次重复实验 `O` 点可改变。
5. 掌握**三力动态平衡矢量三角形**分析（如保持 `O` 点及 `F₁` 方向不变，旋转 `F₂` 方向时在 `F₂ ⊥ F₁` 处 `F₂` 取极小值 `F_eq sin θ₁`），并能迁移解决摩擦力测量、胡克伸长等综合实验题。

## 2. 物理模型（`ML.forces` in `scene.js`）

### 2.1 橡皮条与静力平衡参数
| 参数 | 默认值 | 说明 |
|---|---|---|
| 图钉固定点 `A` | `(0, 0)` m | 坐标原点，向下为 `+y` 方向，向右为 `+x` 方向 |
| 橡皮条原长 `L0` | `0.080` m (`8.0 cm`) | 自然伸直长度 |
| 橡皮条劲度系数 `kBand` | `50.0` N/m | 伸长量 `ΔL = L − L0` 时弹力 `kBand · ΔL` |
| 标准结点 `O` | `(0, 0.160)` m | 伸长 `ΔL = 0.080 m` 沿 `+y`，标准等效力 `F_eq = 4.00 N` |
| 测力计量程 | `0–5.00 N` | 分度值 `0.1 N`，估读到 `0.01 N`；超 `5.00 N` 触发 `overRange` |

### 2.2 双力解析解与误差模型
- 设两细绳拉向分力偏离 `+y` 轴的角度分别为 `θ₁`（左偏，默认 `35°`）与 `θ₂`（右偏，默认 `45°`），总夹角 `α = θ₁ + θ₂`：
  - `F₁ = F_eq · sin θ₂ / sin(θ₁ + θ₂)`
  - `F₂ = F_eq · sin θ₁ / sin(θ₁ + θ₂)`
  - `overRange = (F₁ > 5.0 || F₂ > 5.0)`
- 定量误差源（均由物理公式实时算出）：
  1. **E1 结点未重合 (`knotOffset: {dx, dy}`)**：单拉时结点偏离 `O`（如 `dx = 0.008 m, dy = 0.014 m`），橡皮条实际长度 `L_new = √(dx² + (0.160 + dy)²)`，导致单拉实际力 `F'` 大小 `kBand(L_new − L0)` 与方向均偏离 `F_eq`（相对误差 `> 10%`）。
  2. **E2 测力计未调零 (`zeroErr1, zeroErr2`)**：读数 `F_read = F_true + zeroErr`（如 `+0.30 N`），导致平行四边形合成结果 `F` 相对 `F'` 产生明显系统偏差。
  3. **E3 未与木板平行 (`liftDeg = 22°`)**：测力计及细绳向上抬起 `22°` 并叠加壳体摩擦 `fCase = 0.10 N`，水平分力仍须平衡橡皮条，故读数放大为 `F_read = F_true / cos(liftRad) + fCase`，使理论合力 `F` 显著大于单拉 `F'`。
  4. **E4 细绳过短、描点过近 (`markDist`)**：铅笔描点位置抖动 `σ_pos = 0.0015 m` 引入方向角噪声 `Δθ = atan2(noise, markDist)`；短绳 `0.025 m` 的方向散度约为长绳 `0.120 m` 的 `4.8` 倍。
  5. **E5 夹角极端 (`angleExtreme`)**：夹角 `145°`（`72.5° + 72.5°`）时 `F₁ = F₂ ≈ 6.65 N > 5.0 N` 超量程；夹角过小（`18°`）时平行四边形狭长，微小画线/方向误差被 `1/sin α` 放大。
  6. **E6 误区辨析**：破除“夹角必须为 `90°` 或必须等大”误区，如 `30° + 50°` 同样满足平行四边形定则。
- **动态平衡 (`dynamicEquilibrium`)**：保持结点 `O` 及 `F₁` 方向 `θ₁` 不变，扫描 `θ₂` 得 `F₂ = F_eq · sin θ₁ / sin(θ₁ + θ₂)`，严格在 `θ₁ + θ₂ = 90°`（`F₂ ⊥ F₁`）时取得极小值 `F_eq sin θ₁`。

## 4. 校验（`verify.mjs`）
1. 任意合法角度（`35°+45°`、`30°+50°`）理想合成 `F_theory` 与 `F_actual` 相对误差 `< 0.1%`。
2. `E1` 结点偏移（`dx=0.008 m, dy=0.014 m`）相对误差 `> 10%`。
3. `E2` 零误差（`+0.30 N`）与 `E3` 抬起 `22°` 均导致理论合力相对单拉偏差 `> 5%`（且 `E3` 满足 `F > F'`）。
4. `E4` 短细绳（`0.025 m`）多随机种子角度标准差超过长细绳（`0.120 m`）的 `3.5` 倍。
5. `E5` `145°` 触发 `overRange`（`F₁, F₂ > 5 N`）；`dynamicEquilibrium` 在 `θ₁ + θ₂ = 90°` 严格取得极小值 `F_eq sin θ₁`。
6. `content.json`（`errors ≥ 6, reverse ≥ 4`）与 `questions.json`（`≥ 8` 题全 `verified`、有效数字、表达式及 `plot`）全量自检通过。
