## 1. 教学目标（对应高考考点）
1. 理解单摆做简谐运动的条件：摆角 `< 5°`（此时 `sinθ ≈ θ`）、同一竖直面内摆动（不作圆锥摆）。
2. 明确摆长定义 `L = l + d/2`（悬点到摆球球心的距离）：游标卡尺测直径 `d`（不估读），刻度尺在**自然悬挂状态**测摆线长 `l`；选用**质量大、体积小**的金属球与细、轻、伸缩性小的丝线，悬点用铁夹夹紧。
3. 掌握计时与计数规范：在**最低点**（速度最大，计时位置误差最小）开始计时，按下停表瞬间数 **“0”**，同方向再次经过最低点记为 1 次全振动，累计测 `n = 30` 次（避免把 `(n - 1)` 次记成 `n` 次）；机械停表不估读（注意半分钟红线）。
4. 掌握 `L - T²` 图像法（或两点斜率法 `g = 4π²(L₂ - L₁)/(T₂² - T₁²)`）消除“漏加球半径”或“重心不在球心”带来的摆长恒定偏差。
5. 掌握数字化拓展方案：拉力传感器 `F - t` 曲线中相邻两波峰（或波谷）间隔为 **`T/2`**（`T = 2(t₂ - t₁)`）；光电门在最低点从第 1 次遮光计时到第 `n` 次遮光用时 `t`，周期 `T = 2t/(n - 1)`。
6. 能定量和定性分析常见误差来源（计时点位置、计数差 1、摆长口径、悬点松动、大摆角、空气阻力与浮力）。

## 2. 物理模型（`ML.pendulum`，Node 与浏览器通用）

### 2.1 四阶龙格-库塔（RK4）非线性动力学方程
| 参数 | 默认值 | 可选 / 范围 |
|---|---|---|
| `g` | `9.80 m/s²` | 真实重力加速度 |
| 摆线长 `l` | `0.80 m` | `0.50 – 1.20 m` |
| 钢球直径 `d` | `19.0 mm` | 10 分度游标卡尺测量 |
| 摆球材质 `bob` | `'steel'`（钢球 `28 g`, `19.0 mm`） | `'steel'` / `'foam'`（泡沫球 `2.5 g`, `38.0 mm`） |
| 悬点类型 `pivot` | `'clamp'`（铁夹夹紧） | `'clamp'` / `'loose'`（绕杆松动，摆动中有效摆长增加 `+0.042 m`） |
| 初始摆角 `thetaDeg` | `4°` | `3° – 38°`（支持快捷设 `4°` / `35°`） |
| 积分步长 `dt` | `1/240 s` | 固定步长 RK4，零点交叉线性插值 |

角加速度方程：
`α(θ, ω) = -(g_eff / L_eff) sinθ - b_lin · ω - c_quad · |ω| · ω`

- 理想条件：无空气浮力、无附加质量、无阻力（`g_eff = g`, `b_lin = 0`, `c_quad = 0`），无读数/反应噪声。
- 真实条件：考虑空气浮力 `ρ_air V`、附加质量 `0.5 ρ_air V` 与二次空气阻力 `½ ρ_air C_d A L_eff³ ω²`（对轻质大体积泡沫球产生明显的周期拉长和振幅衰减）。
- 拉力传感器瞬时拉力：`F(t) = m (g_eff cosθ + L_eff ω²)`，在最低点（`θ = 0`）取极大值、最高点（`ω = 0`）取极小值，每周期出现两次极大值，峰间距 `T/2`。

- 多组数据表与 `ML.Chart`：记录单组/一键采齐 5 组数据，作 `L - T²` 拟合直线求 `g = 4π²k`，直观展示漏加半径时直线平行移动而斜率求出的 `g` 依然准确。

### 3.3 ③ 诊·误差（6 项错误操作 + 4 项结果反推）
- `E1` 在最高点而非最低点计时（20 次模拟反应时间误差对比）
- `E2` 把按下停表瞬间记为第 1 次（`(n-1)` 次记成 `n` 次 → `g` 偏大）
- `E3` 摆长未加球半径或取到球下沿 vs `L - T²` 斜率法消偏对比
- `E4` 细线绕在铁杆上未夹紧（摆动中摆长变大、`T` 偏大 → `g` 偏小）
- `E5` 摆角过大（`35°`，RK4 非线性周期变长 → `g` 偏小）或圆锥摆
- `E6` 选用轻质大体积泡沫球（振幅迅速衰减、浮力与阻力使 `g` 偏小）
- 反推 `R1–R4`：`g` 偏大原因多选、`L - T²` 非零截距但斜率求 `g` 不变、`F - t` 曲线峰距 `T/2` 判定、重心偏下两点斜率法 `g` 等于真实值。

## 4. 校验（`verify.mjs`）
1. 小摆角 `4°` RK4 周期与 `2π√(L/g)` 偏差 `< 0.1%`。
2. 大摆角 `35°` RK4 周期符合 `1 + θ₀²/16` 增大幅度（与一阶近似偏差 `< 0.1%`、与四阶精确椭圆积分 `< 0.02%`）。
3. `(n-1)` 误记为 `n` 时 `g_测 / g_真 = (n/(n-1))²`。
4. 漏加球半径时单组 `g` 偏小（`> 1%`），但 5 组 `L - T²` 拟合斜率算出的 `g` 与真实 `g` 偏差 `< 0.2%`。
5. 力传感器 `F - t` 每周期两个拉力峰值，相邻峰间隔等于 `T/2`。
6. `questions.json` 全部题目有效数字、数值容差与含 `π` 表达式自洽校验。
