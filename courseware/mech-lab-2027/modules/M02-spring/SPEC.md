## 1. 教学目标（对应高考考点）
1. 理解胡克定律 `F = kx`：在弹性限度内，弹簧弹力大小 `F` 与伸长量（或压缩量）`x` 成正比；劲度系数 `k` 由弹簧自身材料、长度、粗细和匝数决定，与外力无关。
2. 掌握**竖直悬挂测原长 `l₀`** 的规范原因：消除弹簧自身重力导致的伸长 `Δl_self = m_弹 g / (2k)`；理解水平平放测 `l₀` 时 `F-x` 图像在 `x` 轴正半轴产生截距 `Δl_self`、但直线斜率仍等于真实 `k`。
3. 掌握毫米刻度尺的规范读数：最小分度 `1 mm`，必须**估读到下一位（`0.1 mm = 0.01 cm`）**，对齐整刻线时末尾的 `0` 不可省略；读数时视线须与刻度面垂直（正视指针），避免视差。
4. 掌握图像法数据处理（`F-x` 图像与 `F-l` 图像）：作平滑拟合直线，舍去偏差过大的坏点及超限点，利用斜率 `k = ΔF / Δx = ΔF / Δl` 求劲度系数；理解 `F-l` 图像横截距即自然原长 `l₀`。
5. 理解弹性限度与塑性形变：拉力超过弹性限度后，`F-x` 图像（横轴 `x`、纵轴 `F`）末端向 **`x` 轴方向弯曲**，卸载后留下永久伸长量。
6. 掌握高考创新变式：水桶加水法（`x-V` 图斜率 `ρg/k` 与桶重截距 `m_桶 g/k`）、压力传感器 + 螺旋测微器测压缩弹簧（`F-l` 向下倾斜直线）、双弹簧串联 `k₁k₂/(k₁+k₂)` 与并联 `k₁+k₂`。

## 2. 物理模型（`ML.spring`，Node 与浏览器通用）

### 2.1 弹簧预设参数
| 预设 | `l0Horiz` (m) | `k` (N/m) | `mSpring` (kg) | `fYield` (N) | 自重伸长 `Δl_self` (cm) |
|---|---|---|---|---|---|
| `std`（默认） | `0.140` | `49.0` | `0.024` | `4.00` | `0.24` |
| `soft`（较软） | `0.120` | `25.0` | `0.015` | `3.20` | `0.294` |
| `stiff`（较硬） | `0.110` | `98.0` | `0.036` | `6.00` | `0.18` |
| `heavy`（大自重对照） | `0.140` | `49.0` | `0.060` | `4.00` | `0.60` |

### 2.2 动力学与误差参数化
- 竖直悬挂自然原长：`l0Hang = l0Horiz + (mSpring * g) / (2 * k)`。
- 超出弹性限度塑性变形（`cNl = 0.025 m/N²`）：
  - `F <= fYield`：`xEl = F / k`
  - `F > fYield`：`xEl = F / k + cNl * (F - fYield)²`
  - 历史最大载荷 `fMax > fYield` 产生的永久伸长：`xPerm = 0.55 * cNl * (fMax - fYield)²`
  - 总长度：`lTrue = l0Hang + max(xEl, F / k + xPerm)`，卸载至 `F = 0` 后保留永久伸长 `xPerm > 0`。
- 阻尼简谐振动：`oscPos(yEq, amp, t, spring, mLoad) = yEq + amp * exp(-ζ ω₀ t) * cos(ω_d t)`（`ζ = 0.22`，`ω₀ = √(k / (mLoad + mSpring/3))`），既用于加减钩码后的真实回弹动画，也用于 `E3` 未静止读数采样。
- 视差与刻度尺偏斜：`readScale(trueL, opts)`：
  - `dGap = 0.012 m`；俯视 `+18°` 引起读数偏大 `+dGap * tan(18°)`，仰视 `-18°` 引起读数偏小 `-dGap * tan(18°)`；
  - 刻度尺倾斜 `rulerTiltDeg = 12°` 时读数 `lMeas = trueL / cos(12°)`，使斜率 `k_meas = k * cos(12°)` 偏小约 `2.2%`；
  - `ideal: false` 时叠加以 `0.2 mm`（`0.0002 m`）为标准差的高斯读数噪声。
- 拟合与变式计算：`fitFL(rows)`、`fitFX(rows)`、`comboK(k1, k2, mode)`、`analyzeWaterBucket(Vs, xs, rho, g)`。

## 4. 校验（`verify.mjs`）
1. 四种预设弹簧竖直悬挂原长 `l0Hang` 数值与解析公式完全一致。
2. 弹性限度内 `fitFL`、`fitFX` 拟合 `k` 与真值偏差 `< 0.1%`，`l0Fit` 等于 `l0Hang`。
3. 大自重弹簧（`60 g`）水平测 `l₀` 时 `F-x` 横截距等于 `Δl_self = 0.60 cm`，斜率仍等于 `k`。
4. 超出弹性限度后切线斜率 `< 0.8 k`，卸载回 `0 N` 后保留永久伸长 `> 0`。
5. 刻度尺倾斜 `12°` 使测得劲度系数变为 `k * cos(12°)`；未静止读数引起方差增大、`R²` 明显下降。
6. 2025 四川水桶加水模型 `analyzeWaterBucket` 精确给出 `k = 49 N/m`、`mBucket = 0.028 kg`；`comboK` 串并联正确。
