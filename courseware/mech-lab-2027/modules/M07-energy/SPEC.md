## 1. 教学目标（对应高考考点与学习清单 实验⑦）
1. 理解用自由落体运动验证机械能守恒定律的原理：`mgh = ½mv²`（以及非零起点 `mgΔh = ½mv₂² − ½mv₁²`），明确**为什么不需要用天平测量重物质量 m**（等式两边约去 `m`，比较 `gh` 与 `½v²` 即可），同时明确**必须使用当地真实重力加速度 g**。
2. 掌握竖直安装打点计时器的规范：限位孔在同一竖直线上、纸带竖直拉直；**重物应选密度大、体积小、质量大的金属块**（减小 `f/mg` 阻力比）；**手提纸带上端，重物紧靠打点计时器下方，先接通电源后释放**。
3. 掌握**首两点间距 `≈ 2 mm` 判据**：`h₁ = ½gT² = ½ × 9.80 × 0.02² = 1.96 mm ≈ 2 mm`；若首两点间距明显大于 `2 mm`，说明先释放后通电（有初速度），若误把第 1 点当静止起点会导致 `ΔEₖ > ΔEₚ`。
4. 守住**瞬时速度求法红线**：只能用中间时刻平均速度 `vₙ = (hₙ₊₁ − hₙ₋₁)/(2T)`，**严禁用 `v = gt` 或 `v = √(2gh)`**（循环论证，误差恒为 0）。
5. 掌握图像法处理数据：`½v² - h` 直线斜率 `k = g`；`v² - h` 直线斜率 `k = 2g`；反取零点（向上为正）`½v² - h` 斜率 `k = −g`；以及气垫导轨光电门方案 `v = d/Δt`、`Δh = L·sinθ`。
6. 能识别**逻辑性错误**（2024·浙江 6 月选考）：绝不能用纸带自身求出的加速度 `a` 代替当地 `g` 计算势能减小量（否则恒有 `½v² ≡ a·h`，掩盖了阻力做功）。

## 2. 物理模型

### 2.1 竖直自由落体（`ML.tape` `mode: 'drop'`）
| 参数 | 默认 | 可选 / 说明 |
|---|---|---|
| 当地 `g` | `9.80 m/s²` | 参考线 `y = gx` 斜率基准 |
| 重物材质 `bob` | `'iron'`（300 g） | `'iron'`（300 g）/ `'al'`（100 g）/ `'wood'`（40 g） |
| 计时器 `timer` | `'em'`（电磁 8 V~） | `'em'`（`fTape = 0.035 N`）/ `'spark'`（220 V~，`fTape = 0.008 N`） |
| 空气阻力 `fAir` | 随材质变化 | `iron: 0.020 N` / `al: 0.025 N` / `wood: 0.045 N`（理想条件为 `0`） |
| 下落总行程 `L` | `0.70 m` | 靠近计时器释放 `0.70 m`；远离计时器 `startAt = 0.28 m` → `0.42 m` |
| 操作顺序 `order` | `'power-first'` | `'power-first'`（`lag = 0.40 s`）/ `'release-first'`（`lag = 0.12 s`） |

加速度 `a = (m·g − f_tape − f_air) / m`：
- 理想条件：`a = 9.800 m/s²`，`h₁ = ½gT² = 1.96 mm`，理论能耗损 `0%`。
- 真实铁锤（电磁）：`a ≈ 9.617 m/s²`，相对损耗 `≈ 1.87% < 2%`；电火花：`a ≈ 9.707 m/s²`，损耗 `≈ 0.95%`。
- 真实木块（电磁）：`a = 7.800 m/s²`，相对损耗 `≈ 20.4% > 15%`。

### 2.2 倾斜气垫导轨 + 光电门支线
- 导轨倾角正弦 `sinθ ∈ {0.05, 0.06, 0.08, 0.10}`，两光电门间距 `L ∈ {0.25, 0.40, 0.55} m`，竖直高度差 `Δh = L·sinθ`。
- 遮光片宽度 `d ∈ {2, 5, 10, 20} mm`；气轨残余阻力系数 `μ_air = 0`（理想）/ `0.0015`（真实），`a = g·sinθ − μ_air·g·cosθ`。
- 解析求解遮光时间 `Δt₁, Δt₂`，瞬时速度近似 `vᵢ = d/Δtᵢ`，比较 `g·Δh` 与 `½(v₂² − v₁²)`，记录多组数据作 `½Δv² - Δh` 图验证斜率 `= g`。

## 4. 校验（`verify.mjs`）
1. 理想落体首两点间距 `≈ 1.96 mm`（偏差 `< 0.05 mm`）。
2. 理想条件从 `n ≥ 4` 起 `½vₙ² / (g hₙ)` 偏差 `< 0.5%`，`½v² - h` 拟合斜率与 `g` 偏差 `< 0.5%`。
3. 真实铁锤相对损耗 `< 2%`；真实木块（电磁）相对损耗 `> 15%`。
4. 用纸带自身 `a` 代替当地 `g` 计算时，即使在木块大阻力下 `|½vₙ² − a·hₙ| / (a·hₙ)` 偏差 `< 0.2%`（恒等式验证）。
5. 先释放后通电（`lag = 0.12 s`）：首两点间距 `>> 2 mm`，若以首点为静止起点则 `ΔEₖ > ΔEₚ`；误用 `v = √(2gh)` 相对误差恒为 `0`。
6. 气垫导轨光电门方案：`½(v₂² − v₁²) / (g L sinθ)` 偏差在理想模式下 `< 0.5%`。
7. `questions.json` 全部题目数值、有效数字、`show` 字段、表达式等价性与 `replay` 引用自检。
