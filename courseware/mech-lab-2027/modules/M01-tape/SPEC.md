## 1. 教学目标（对应高考考点）
1. 会正确安装、操作打点计时器（电源种类、先通电后释放、靠近计时器释放、到滑轮前按住）。
2. 会处理纸带：舍去密集点、选计数点（每 5 个点取 1 个 → T = 0.1 s）、从同一起点量位置。
3. 会用 vₙ = (xₙ + xₙ₊₁)/2T 求瞬时速度、用 Δx = aT² 判断匀变速、用**逐差法**和 **v-t 图像斜率**求 a；理解“剪纸带贴条”。
4. 光电门：v = d/Δt 是平均速度（遮光片越窄越接近瞬时速度）；a = (v₂² − v₁²)/2x 与 a = (v₂ − v₁)/t 的系统误差差异。
5. 能对“频率偏差、T 取错、先释放后通电”等做误差判断。
6. 明确：本实验**不需要**补偿阻力、**不需要**槽码质量远小于小车质量（阻力恒定时仍是匀加速）。

## 2. 物理模型（scene / tape-model）

### 2.1 小车—槽码系统（水平长木板）
| 参数 | 默认 | 可选 / 范围 |
|---|---|---|
| g | 9.80 m/s² | — |
| 小车质量 M | 0.400 kg | 0.300 / 0.400 / 0.500 |
| 槽码质量 m | 0.050 kg | 0.020–0.100，步长 0.010 |
| 滚动阻力系数 μ | 0.020（真实） / 0（理想） | — |
| 纸带阻力 f_tape | 电磁 0.030 N / 电火花 0.005 N（真实）；0（理想） | — |
| 木板垫高角 θ | 0° | 0°–4°（仅“需要补偿阻力吗？”试一试使用） |
| 可运动行程 L | 0.70 m（小车靠近计时器时）| 起点不靠近时为 0.35 m |

a = [m·g + M·g·sinθ − μ·M·g·cosθ − f_tape] / (M + m)；若 a ≤ 0 小车不动（显示“拉不动”）。
默认值下 a ≈ 0.849 m/s²（真实）/ 1.089 m/s²（理想）。

### 2.2 打点
- 频率 f（默认 50 Hz；“频率偏差”试一试取 51 Hz 或 49 Hz），周期 T₀ = 1/f。
- 时间轴：t = 0 为第一次操作时刻。`powerOn` 时刻 t_p、`release` 时刻 t_r 由学生操作顺序决定；正确顺序 t_r − t_p = 0.40 s（自动，约 20 个点叠在起点）；先释放后通电时 t_p − t_r = 0.30 s。
- 第 k 个点时刻 t_k = t_p + k·T₀，打在纸带上的位置 = 小车在 t_k 的位移 s(t_k)（纸带随小车运动）。点位置加针尖抖动噪声 σ = 0.05 mm（理想模式为 0）。
- 运动结束：到达行程末端。若学生按了“按住小车”则平稳停住；否则撞击滑轮（结束处点迹急停堆积 + 标签“未在滑轮前按住小车”）。
- 电源判定：电磁 + 8 V 交流 ✓；电火花 + 220 V 交流 ✓；任意 + 直流 → 不打点；电火花 + 8 V 交流 → 不打点（不能产生火花）；电磁 + 220 V 交流 → 不允许运行，提示“电压远超额定，线圈可能烧毁”，记错误标签。

### 2.3 测量（刻度尺读数）
- 毫米刻度尺，估读到 0.1 mm，记录单位 cm、保留两位小数。
- **同一起点读数**：每个计数点位置 dₙ = 真值 + N(0, 0.15 mm)，四舍五入到 0.1 mm；xₙ = dₙ − dₙ₋₁。
- **逐段读数**：每段 xₙ = 真值 + N(0, 0.15 mm)×√2（两端各读一次）+ N(0, 0.20 mm)（对零误差），四舍五入到 0.1 mm；位置由各段累加 → 误差随 n 累积。
- 理想模式：读数噪声为 0，但仍四舍五入到 0.1 mm。

### 2.4 光电门
- 两光电门距离 x = 0.400 m，光电门 1 距小车出发点 0.200 m；遮光片宽度 d ∈ {2, 5, 10, 30} mm（30 mm 为“过宽”）。
- 遮光时间 Δt = 遮光片从前沿到达到后沿离开所用时间（解析解求根）；数字计时器显示 4 位有效数字（ms）。两门间时间 t = 两遮光片前沿到达两光电门的时间差。
- 显示 v = d/Δt；a₁ = (v₂² − v₁²)/2x；a₂ = (v₂ − v₁)/t；与模型 a 对比，给出相对偏差。

## 3. 界面与交互

### 3.1 学·原理（7 页，分步揭示）
L1 实验目的与思路 → L2 打点计时器（两种计时器对比卡）→ L3 纸带记录了什么（点 = 位置 + 时刻）→ L4 中间时刻速度（三步推导）→ L5 Δx = aT² 与逐差法（为什么要逐差：两点法 vs 逐差法，用同一条纸带数据对比）→ L6 v-t 图像与剪纸带 → L7 光电门。器材卡 8 张（点器材出卡）。

### 3.2 做·实验
**实验台（Canvas，侧视）**：桌面、一端带滑轮长木板、打点计时器（无滑轮一端）、学生电源（档位：交流 8 V / 交流 220 V / 直流 8 V，220 V 为插座）、小车、纸带、细绳、槽码。
热区（≥ 44 px）与面板按钮一一对应：

| 操作 | 实验台 | 面板按钮 |
|---|---|---|
| 选计时器 | 点计时器切换 | 电磁 / 电火花 |
| 选电源 | 点电源旋钮 | 三档按钮 |
| 穿纸带 | 点纸带卷 | “穿纸带” |
| 挂槽码 | 点槽码 | − / + 槽码质量 |
| 小车位置 | 拖动小车，靠近计时器处吸附（±2 cm） | “靠近计时器” / “放在木板中部” |
| 接通电源 | 点电源开关 | “接通电源” |
| 释放小车 | 点小车 | “释放小车” |
| 按住小车 | 运动中出现“按住”大按钮 | 同 |
| 取下纸带 | — | “关闭电源，取下纸带” |

**引导模式**：步骤列表逐条打勾；做错时不执行，而是给出“为什么”+“试一试”入口。
**自由模式**：任意顺序，不拦截；产生的纸带挂“本次操作有问题”标签（可多个），点开进入对应四拍试一试。

**光电门支线**：实验台顶部切换“打点计时器 / 光电门”。光电门模式：两门 + 数字计时器 + 遮光片宽度选择；释放后显示 Δt₁、Δt₂、t。

**处理纸带（取下纸带后进入）**：
1. 纸带全长视图（可左右拖动，放大镜查看点迹）。
2. 选起点 O：点任意点；若点在密集区（相邻间距 < 1 mm）挂标签 E4。
3. 取计数点：“每 5 个点取 1 个计数点”（默认）/“每个点都是计数点”。最多取 7 个计数点（x₁…x₆）。
4. 测量方式：同一起点 / 逐段（E5）。点“测量”→ 刻度尺滑入，逐个计数点在放大镜中闪示读数并填入数据表。
5. 计算面板：先选 T（0.02 s / 0.10 s 芯片，选错 → E3 标签）；表格显示 xₙ、Δxₙ、vₙ；逐差公式展开代入、得 a；v-t 图（描点 + 最小二乘直线 + 斜率）；“剪纸带”条形视图切换。与模型 a 对比显示相对偏差（“理想”时偏差 < 0.5%）。

### 3.3 诊·误差
**A. 错误操作实验室**：列出 `errors[]` 卡片。每卡“试一试”按四拍执行：布置（只显示 observe）→ 运行（同种子分别跑正确与错误配置）→ 对比（纸带上下对齐 / 数值对照 / 散布图）→ 追问（`ask`）→ 揭示（`consequence` + `why` + 关联注意事项）→“恢复正确操作”。

| id | 名称 | 对比形式 |
|---|---|---|
| E1 | 先释放小车，后接通电源 | 纸带上下对齐，圈出起点处无密集点、首段间距大、总点数少 |
| E2 | 电源接错 | 纸带：空白（直流 / 电火花接 8 V）；电磁接 220 V：不运行 + 警示 |
| E3 | 计数周期取成 0.02 s | 同一组数据两种 T 计算，a 相差 25 倍 |
| E4 | 从开头密集点取计数点 | 纸带圈出起点；20 次重复测量的 a 散布对比 |
| E5 | 逐段测量 | 20 次重复测量的位置误差随 n 增长曲线 + a 散布 |
| E6 | 小车没有靠近打点计时器 | 纸带对齐，有效点数对比 |
| E7 | 未在滑轮前按住小车 | 纸带末端急停堆积 |
| E8 | 遮光片过宽 + 用 (v₂−v₁)/t | d = 2 mm 与 30 mm 两组 a₁、a₂ 对照表 |
| E9 | 实际频率 51 Hz 仍按 50 Hz 计算 | 两纸带对齐（51 Hz 点更密），a 计算值偏小 |
| M1 | 误区：本实验需要补偿阻力？ | 有阻力 / 垫高补偿 两纸带 Δx 都恒定（v-t 都是直线） |

**B. 结果反推**（≥ 2，`reverse[]`）：R1 纸带开头无密集点（→E1）；R2 算出 a 约 21 m/s²（→E3）；R3 频率 51 Hz 时 a 偏大还是偏小（→E9）；R4 v-t 图不过原点（→ 正常：纵截距是计时起点的速度）。答后“去实验台复现”把实验台设为对应错误配置（自由模式）。

## 5. 校验（verify.mjs）
1. 理想模式、默认参数：取 6 段逐差 a 与模型 a 偏差 < 0.5%；v-t 拟合斜率偏差 < 0.5%。
2. 真实模式 200 次随机种子：同一起点读数的 a 标准差 < 逐段读数的 a 标准差。
3. 先释放后通电：首个点处小车速度 > 0；点数少于正确顺序。
4. T 取 0.02 s：a 计算值 = 25 × 正确值（±0.1%）。
5. 51 Hz 按 50 Hz 计算：a 计算值 / 模型 a = (50/51)²（±0.5%，理想模式）。
6. 光电门：d = 2 mm 时 a₁、a₂ 偏差 < 0.5%；d = 30 mm 时 a₂ 偏小且偏差 > 1%，a₁ 偏差 < 0.5%。
7. 补偿阻力误区：θ 取 tanθ = μ + f_tape/(Mg) 时 a = mg/(M+m)；θ = 0 时 Δx 的相对极差 < 1%（理想读数）。
8. 电源：直流 / 电火花 8 V 时 0 个点。
