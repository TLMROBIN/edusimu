## 1. 教学目标（对应高考考点）
1. 理解动量守恒定律的验证思路：$m_1 v_1 + m_2 v_2 = m_1 v_1' + m_2 v_2'$，掌握系统合外力为零（或碰撞内力远大于外力）的实验条件。
2. 掌握三套测速方案：
   - **斜槽平抛落地法**：斜槽末端水平、两球半径相等、$m_1 > m_2$（防反弹）、从同一位置静止释放，利用等高平抛飞行时间相同，以水平射程代替初速度，验证 $m_1 \cdot OP = m_1 \cdot OM + m_2 \cdot ON$。
   - **气垫导轨 + 双光电门法**：调平导轨（两门遮光时间相等），用游标卡尺/螺旋测微器测遮光片宽度 $d$，由 $v = d/\Delta t$ 测速度（支持弹性碰、粘连完全非弹性碰、烧线弹簧弹开）。
   - **双摆碰撞法**：等长细绳挂等径两球，由 $h = l^2/(2L)$ 得 $v \propto l$，用弦长代速度，注意反弹项取负号。
3. 掌握“画尽量小的圆把落点圈住，圆心为平均落点”的数据处理方法。
4. 掌握弹性碰撞的附加判据：斜槽法中 $OP + OM = ON$（与质量无关）；等质量光电门小车碰撞中 $t_2 = t_1$；粘连碰撞动能比 $\frac{E_k'}{E_{k0}} = \frac{m_1}{m_1 + m_2}$。
5. 能分析“$m_1 < m_2$ 反弹、释放位置不固定、斜槽末端不水平、单次不画圆、气垫导轨未调平、误以为必测下落高度 $H$”等误差与误区。

## 2. 物理模型（`ML.m08phys`）

### 2.1 方案一：斜槽平抛落地法
| 参数 | 默认值 | 可选 / 范围 |
|---|---|---|
| 重力加速度 $g$ | $9.80\text{ m/s}^2$ | — |
| 桌面高度 $H$ | $0.500\text{ m}$ | $0.500\text{ m}$ / $0.800\text{ m}$（误区 E6 对照） |
| 理想出槽初速度 $v_0$ | $1.50\text{ m/s}$ | $H = 0.500\text{ m}$ 时射程 $OP \approx 47.9\text{ cm}$ |
| 入射球 $m_1$ | $45\text{ g}$（钢球） | $45\text{ g}$ 钢 / $15\text{ g}$ 硬铝 / $12\text{ g}$ 玻璃（半径相同） |
| 被碰球 $m_2$ | $15\text{ g}$（硬铝球） | $45\text{ g}$ 钢 / $15\text{ g}$ 硬铝 / $12\text{ g}$ 玻璃 |
| 恢复系数 $e$ | $0.98$（弹性） / $1.00$（理想） | $0.98$（弹性）/ $0.75$（非弹性） |
| 斜槽末端倾角 $\alpha$ | $0^\circ$ | $0^\circ$（水平）/ $+12^\circ$（上翘，误差 E3） |
| 释放位置扰动 | 关闭 | 真实固定 $\sigma_v/v_0 = 1.5\%$；不固定 $\sigma_v/v_0 = 10\%$（误差 E2） |

- **正碰公式**：$v_1' = \frac{m_1 - e m_2}{m_1 + m_2} v_0$，$v_2' = \frac{(1 + e) m_1}{m_1 + m_2} v_0$。
  - 当 $m_1 > m_2$ 时，$v_1' > 0$，两球均向前飞出。
  - 当 $m_1 < m_2$ 时，$v_1' < 0$，入射球沿斜槽反弹回滚并损耗部分机械能后再次滑下，实际出槽速度大幅畸变，动量表达式失真。
- **平抛飞行时间**（$v_{y0} = -v \sin\alpha$）：$t(v) = \frac{v \sin\alpha + \sqrt{(v \sin\alpha)^2 + 2gH}}{g}$，水平射程 $x(v) = (v \cos\alpha) \cdot t(v)$。当 $\alpha = 0^\circ$ 时 $t(v) \equiv \sqrt{2H/g}$ 与速度无关；当 $\alpha \neq 0^\circ$ 时，飞行时间随速度变化，射程不再正比于速度。
- **最小圆定心**：采用精确最小包围圆算法（遍历两球心直径圆与三点外接圆取最小半径），计算圆心 $(x_c, y_c)$ 及到 $O$ 点的径向距离与半径 $R$。

### 2.2 方案二：气垫导轨 + 双光电门
| 参数 | 默认值 | 可选 / 范围 |
|---|---|---|
| 光电门 1 / 2 位置 | $0.35\text{ m}$ / $0.85\text{ m}$ | 两门间距 $0.50\text{ m}$ |
| 滑块质量 $m_1, m_2$ | $200\text{ g}, 100\text{ g}$ | $100\text{ g}$ / $200\text{ g}$ / $300\text{ g}$ |
| 遮光片宽度 $d_1, d_2$ | $10.00\text{ mm}$ | $6.860\text{ mm}$ / $10.00\text{ mm}$ / $20.00\text{ mm}$（支持游标卡尺/螺旋测微器读数传入） |
| 导轨倾角 $\theta$ | $0^\circ$ | $0^\circ$（水平）/ $+0.6^\circ$ / $+1.35^\circ$（左低右高减速） |
| 运行模式 | `elastic` | `elastic`（弹性碰）/ `inelastic`（粘连碰）/ `spring`（烧线弹簧弹开） |

- 碰撞/弹开速度：
  - `elastic` / `inelastic`：$v_1' = \frac{m_1 - e m_2}{m_1 + m_2} v_{10}$，$v_2' = \frac{(1 + e) m_1}{m_1 + m_2} v_{10}$（$e = 0$ 时完全非弹性粘连，$E_k'/E_{k0} = \frac{m_1}{m_1 + m_2}$）。
  - `spring`（压缩弹簧弹性势能 $E_p = 0.060\text{ J}$）：$v_1 = \sqrt{\frac{2 E_p m_2}{m_1(m_1 + m_2)}}$，$v_2 = \sqrt{\frac{2 E_p m_1}{m_2(m_1 + m_2)}}$，方向相反，$m_1 v_1 = m_2 v_2$。
- 含加速度的精确遮光时间：在倾角 $\theta$（$a = -g\sin\theta - \mu_{\text{air}} g\cos\theta$）下，由遮光片前后沿运动学方程精确求 $\Delta t$。

## 4. 校验（`verify.mjs`）
1. 斜槽法 `m₁ > m₂` 弹性与非弹性碰撞在理想水平末端下，$m_1 \cdot OP = m_1 \cdot OM + m_2 \cdot ON$ 相对偏差 $< 0.1\%$。
2. 斜槽法 `m₁ < m₂` 时，入射球碰撞瞬时速度 $v_1' < 0$（反向反弹），且再滑落后的总动量表达式失真。
3. 弹性碰撞（$e = 1$，$m_1 > m_2$）满足 $OP + OM = ON$（相对偏差 $< 0.1\%$），非弹性（$e = 0.75$）不满足。
4. 气垫导轨水平弹簧弹开满足 $m_1 d_1/\Delta t_1 = m_2 d_2/\Delta t_2$（偏差 $< 0.1\%$）；粘连碰撞动能比等于 $m_1/(m_1 + m_2)$；歪斜导轨两门遮光时间不等。
5. 固定释放位置 vs 变位置释放：变位置释放落点最小圆半径明显大于固定位置释放（$> 3$ 倍）。
6. 斜槽末端上翘 $+12^\circ$ 时，各球飞行时间不等，$m_1 \cdot OP$ 与 $m_1 \cdot OM + m_2 \cdot ON$ 出现明显偏差。
7. `questions.json` 全部题目有效数字、`show` 字段与表达式等价性自检。
