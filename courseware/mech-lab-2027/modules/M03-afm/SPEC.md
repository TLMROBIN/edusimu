## 1. 教学目标（对应高考考点）
1. 理解**控制变量法**：保持 $M$ 不变探究 $a\text{-}F$；保持 $F$ 不变探究 $a\text{-}M$（化曲为直作 $a\text{-}1/M$）。
2. 掌握**补偿阻力（平衡摩擦力）**：把无滑轮一端垫高倾角 $\theta$，**不挂槽码、穿好纸带**，轻推小车使点迹均匀（或两光电门遮光时间相等）；理解 $Mg\sin\theta = \mu Mg\cos\theta + f_{\text{纸带}}$，改变小车质量 $M$ 时无需重新调整倾角。
3. 理解系统误差来源：当不满足 $m \ll M$ 时，槽码处于加速失重状态，细绳拉力 $F_T = \frac{Mmg}{M+m} < mg$，导致以 $mg$ 作横坐标的 $a\text{-}F$ 图末端向下弯曲；改用**力传感器**直接测 $F_T$ 或采用整体法可消除此误差。
4. 熟练利用**纸带逐差法**或**光电门**（$v = d/\Delta t$，$a = (v_2^2 - v_1^2)/(2x)$）计算加速度，并能由 $a\text{-}F$ 图截距、斜率与 $1/a\text{-}M$ 图斜率、截距反推实验误差。

## 2. 物理模型（复用 `ML.tape`）

| 参数 | 默认 | 可选 / 范围 |
|---|---|---|
| 重力加速度 g | 9.80 m/s² | — |
| 小车（含砝码）质量 M | 0.400 kg | 0.200–0.800 kg（步长 0.050 kg） |
| 槽码质量 m | 0 / 0.020 kg | 0–0.250 kg（支持 0、10、20、40、60、100、150、200、250 g 及连续步进） |
| 轨道倾角 θ | 0° | 0°–4.00°（连续调节 / 步进 0.05°） |
| 滚动摩擦系数 μ | 0.020（真实） / 0（理想） | — |
| 纸带阻力 f_tape | 电磁 0.030 N / 电火花 0.005 N / 光电门 0 N | 理想为 0 |
| 轻推初速度 v0 | 0.35 m/s（Phase ① 不挂槽码） | 0（释放实验） |

- 加速度：`accel(p)`：
  - 轻推（`m = 0, v0 > 0`）：`a = (M*g*sinθ - μ*M*g*cosθ - f_tape) / M`
  - 牵引（`m > 0`）：`a = (m*g + M*g*sinθ - μ*M*g*cosθ - f_tape) / (M + m)`（若 ≤ 0 则小车静止不动）
- 细绳真实拉力：`tension(p) = m * (g - Math.max(0, a))`，恰好补偿时 `F_T = M*m*g / (M + m)`。
- 恰好补偿角：`compensateAngle(p)` 二分求解 `M*g*sinθ - μ*M*g*cosθ - f_tape = 0`（电磁约 `1.58°`、电火花约 `1.22°`、光电门约 `1.15°`）。
- 光电门模式：当 `v0 > 0` 或 `a ≤ 0` 时，按运动学二次方程直接求遮光片前沿/后沿到达两光电门时刻，计算 $\Delta t_1$、$\Delta t_2$、$v_1$、$v_2$ 及 $a$，处理减速停下未达第二门的情形。
- 纸带截取：高加速度（大槽码）下行程较短，取计数点严格限制在 `t ≤ tArrive`（按住减速或撞击滑轮前），避免刹车段点迹混入逐差法计算。

### 3.3 ③ 诊·误差（6 个错误操作 + 4 个结果反推）
- `E1` 未补偿阻力或补偿不足（`θ = 0°` → `a-F` 横截距）
- `E2` 补偿阻力过度（`θ = 3.2°` → `a-F` 纵截距）
- `E3` 槽码质量未远小于小车质量（`m` 到 `0.25 kg` → 普通细绳 `a-F` 末端下弯 vs 力传感器直线）
- `E4` 补偿阻力时未穿纸带或挂了槽码
- `E5` 改变小车质量后重新补偿阻力（误区辨析：`M = 0.3 / 0.6 kg` 在同一 `θ₀` 下点迹均均匀）
- `E6` 探究 `a-M` 时直接作曲线而非 `a-1/M` 化曲为直
- `R1`–`R4` 覆盖横截距、纵截距、末端下弯、`1/a-M` 图像斜率与截距判读。

## 4. 校验（verify.mjs）
1. 恰好补偿角下轻推加速度 `≈ 0`（`|a| < 1e-6`），纸带点距均匀；`0°` 与 `3.2°` 分别减速/加速。
2. 改变 `M` 时 `f_tape = 0` 下加速度恒为 0；电火花下 `|a| < 0.005 m/s²`。
3. `m = 0.250 kg, M = 0.400 kg` 时 `tension` 与 `mg` 偏差 `38.5%`；力传感器 `a-F_T` 拟合 `R² > 0.99999`，普通细绳 `a-mg` 末端显著下弯。
4. `a-1/M` 拟合线性度 `R² > 0.999`（含由模拟纸带测出的 `a`）；`1/a-M` 斜率与截距符合解析式。
5. `questions.json` 全部题目自检（`verified:true`、`show` 与 `sig`/`tol` 一致、`expr` 合法、`plot` 完整）。
