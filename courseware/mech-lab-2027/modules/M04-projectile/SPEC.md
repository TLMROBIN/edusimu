## 1. 教学目标（对应高考考点）
1. 理解平抛运动“化曲为直”的探究思路：正交分解为**水平方向匀速直线运动**与**竖直方向自由落体运动**。
2. 掌握**装置 A（平抛竖落仪）**现象与结论：改变释放高度与打击力度，A、B 两球总是同时落地 ⇒ 竖直分运动为自由落体运动（但不证明水平分运动规律，也不要求两球质量相等）。
3. 掌握**装置 B（斜槽描迹法）**操作要领：
   - 斜槽末端切线水平（轻放小球在槽口不滚动）；
   - 背板处于竖直平面内（用重锤线校准并在白纸上标记竖直方向）；
   - 小球每次从斜槽**同一位置由静止**释放（保证初速度相同，斜槽无需绝对光滑）；
   - 坐标原点取抛出时**球心在白纸上的投影**（槽口正上方球半径 `R` 处）；
   - 移动挡板不必等间距，用**平滑曲线**连点（舍去偏差较大点）。
4. 掌握初速度 `v₀` 的两种求法及常见变式：
   - **有抛出点**：任取 `(x, y)` 得 `v₀ = x√(g/2y)`，或作 `y - x²` 图像由斜率 `k = g/(2v₀²)` 求 `v₀`；
   - **无抛出点**：取水平等间距三点（或频闪等时间点），由 `Δy = gT²` 求 `T` 与 `v₀ = x/T`，以及中间点竖直速度 `v_By = (y_AB + y_BC)/(2T)`（切忌套用 `1:3:5`）；
   - **坐标偏移求抛出点**（2026 北京卷）：作 `y/x - x` 直线得斜率 `k` 与截距 `b`，抛出点为 `(−b/(2k), −b²/(4k))`。
5. 理解频闪照相法与误差诊断（末端上翘、释放高度不一、原点偏差 `R`、误用 `1:3:5`、背板偏斜、斜槽粗糙误区）。

## 2. 物理模型（`ML.proj` in `scene.js`）

### 2.1 装置 A：平抛与自由落体对比仪
| 参数 | 默认 | 范围 / 说明 |
|---|---|---|
| 重力加速度 `g` | `9.80 m/s²` | 可按需传入 `9.80` 或 `10.0` |
| 释放高度 `H` | `0.80 m` | `0.40 .. 1.50 m` |
| 水平击打初速度 `v₀` | `1.80 m/s` | `0.80 .. 2.80 m/s` |
| 金属片偏斜角 `tiltDeg` | `0°` | `-8° .. +8°`（正值表示斜向上翘） |
| 条件 `ideal` | `false` | `true`：无阻力解析解；`false`：微弱空气阻尼 + 微小触发抖动 |

- 初速度：`v₀ₓ = v₀ cos α`，`v₀ᵧ = −v₀ sin α`（向下为正）。
- 理想模式落地时间：`t_B = √(2H/g)`，`t_A = (−v₀ᵧ + √(v₀ᵧ² + 2gH))/g`。`α = 0°` 时 `t_A = t_B`；`α = +5°` 时 A 球先微升再落，`t_A > t_B`（声音双脉冲明显分离）。

### 2.2 装置 B：斜槽描迹与频闪照相
| 参数 | 默认 | 范围 / 说明 |
|---|---|---|
| 小球半径 `R` | `0.015 m`（`1.50 cm`） | 用于球心投影 `O` 与槽口下沿 `O'` 对照 |
| 斜槽释放高度 `hDrop` | `0.18 m` | `0.10 .. 0.30 m`（或 `randomHeight: true` 随机变化） |
| 斜槽效率 `η` | `0.85`（光滑） / `0.72`（较粗糙） | `v₀ = η√(2 g hDrop)`；同位置释放时 `v₀` 仍恒定 |
| 末端倾角 `tiltDeg` | `0°` | `-8° .. +8°`（`+5°` 对应末端上翘斜抛） |
| 背板竖直校准 `plumbCalibrated` | `true` | `false` 时背板相对铅垂线偏斜 `6°` 且易刮擦 |
| 原点选择 `originMode` | `'center'` | `'center'`（球心投影 `O`） / `'rim'`（槽口下沿 `O'`，测得 `y' = y − R`） |
| 频闪周期 `T_strobe` | `0.05 s` | 用于频闪照相模式采样 |

- 水平抛出轨迹：`x(t) = v₀ t`，`y(t) = ½ g t²`，消去 `t` 得 `y = g x² / (2 v₀²)`。
- 无抛出点三点法：设 `A, B, C` 水平间隔均为 `Δx`，则 `T = √((y_BC − y_AB)/g)`，`v₀ = Δx / T`，`v_By = (y_AB + y_BC) / (2T)`。
- 原点取在槽口下沿 `O'` 时：`y' = (g / 2v₀²) x² − R`，`y'-x²` 图像产生纵截距 `−R`，斜率不变。

## 4. 校验（`verify.mjs`）
1. 水平抛出轨迹 `y = g x² / (2v₀²)` 与 `y-x²` 线性拟合误差 `< 0.1%`。
2. 等水平间隔三点 `Δy = gT²`、`v₀` 与 `v_By` 解析解误差 `< 0.1%`；验证误用 `1:3:5` 的偏差。
3. 装置 A/B 末端上翘 `5°` 造成落地时间差 `t_A > t_B` 且 `y-x²` 偏离过原点直线。
4. 原点偏差 `R = 0.015 m` 引起 `y-x²` 截距 `−R` 及单点公式 `v₀` 偏大。
5. 随机释放高度（散乱）vs 粗糙斜槽同位置释放（重合良好）；背板偏斜 `6°` 引起 `v₀` 偏差。
6. `questions.json` 全题自检（有效数字、`show`、容差、表达式、`plot` 斜率及 `replay` 引用）。
