# 作答数据收集与课堂弹幕互动实施计划

> 日期：2026-11-19\
> 适用项目：EduSimu（教育动画展示系统，FastAPI + PostgreSQL/SQLite + Vue 3）\
> 核心定位：**弹幕功能 100% 作为纯平台能力优先落地（存量与新增课件零改动）；作答数据收集采用《EduSimu 课件题目规范 v1》准入制（遵循规范自动认题收数，否则按普通动画处理）。**

---

## 一、核心架构决策

### 1. 不做“课件类 vs 纯动画类”硬分类，采用“平台能力 + 规范准入”
平台上承载了普通单文件 HTML、PhET、GeoGebra、`frontend/public/unit-review` 单元课件、`courseware/mech-lab-2027` 力学实验系列，以及通过 `scripts/tongjiang_isolated_wrapper.html` 封装的 54 门铜匠隔离课件。如果按“课件 / 纯动画”做数据模型或前台目录的硬拆分，会引发四类问题：
1. **大量中间态资源难以归类**（如主画面为仿真实验，侧栏或典例附带随堂检测）。
2. **割裂教材章节主线**（违背 `PRODUCT.md` 中“统一绑定教材章节、快速定位进入播放”的定位）。
3. **资源演进时的维护断层**（纯动画加题若漏改手工分类字段，统计入口就会失效）。
4. **与 `Animation.source_type` 语义冲突**（`source_type` 已用于区分 `original` / `phet` / `geogebra`）。

**最终方案**：
- **弹幕与课堂提问（纯平台能力）**：直接构建在外层播放器 `frontend/src/views/AnimationPlayer.vue` 与平台后端上。无论内部加载的是普通 HTML、PhET、GeoGebra 还是隔离沙箱课件，**课件一行代码都不用改**，所有弹幕与提问数据完全属于平台。
- **作答数据收集（规范准入能力）**：平台不通过脆弱的 DOM 注入去猜测黑盒 HTML 内部题目，而是制定明确的**《EduSimu 课件题目规范 v1》**。上传时由后端自动识别规范声明并建档；未遵循规范的资源自动视为普通动画，仅开放平台弹幕能力，不显示空的作答报表。

### 2. 课堂弹幕管控规则（限时飘屏 + 常驻历史提问墙）
将课堂互动拆分为**“实时飘屏弹幕（40 分钟限时）”**与**“课件历史弹幕区 / 提问墙（常驻沉淀）”**两层形态，既保证课堂纪律，又让有价值的提问真正留存下来：
- **实时飘屏与发言（默认关闭 + 教师开启 + 40 分钟自动关闭）**：
  - **默认关闭**：所有班级、所有课件的实时弹幕默认处于关闭状态；学生进入播放页时不展示弹幕轨道与发言入口，也不触发高频轮询。
  - **教师按班开启**：仅教师或管理员可在播放页针对指定班级（权限校验复用 `backend/app/routers/game.py` 的 `teacher_classes` 逻辑）开启本堂课弹幕。
  - **单次最长 40 分钟无状态自动关闭**：每次开启写入 `expires_at = opened_at + 40 分钟`；无论教师是否手动提前关闭，一旦超过 `expires_at`，后端读/写接口即刻判定会话已结束（`is_open = false`），拒绝新弹幕写入，前端同步停止高频轮询并收起实时飘屏界面，无需后台定时任务或 Cron 清理。
  - **实时飘屏范围**：飘屏仅展示当堂 40 分钟会话内本班发出的消息，杜绝跨班与往期历史消息干扰课堂演示。
- **课件历史弹幕区 / 提问墙（常驻沉淀 + 随时点赞同问）**：
  - **常驻入口**：播放页普通模式右侧栏独立展示“课件历史弹幕区 / 提问墙”（沉浸模式可通过悬浮按钮按需展开抽屉），持久保留历次课堂学生提出的问题（自动过滤教师已删除的灌水消息）。
  - **随时可看可点赞**：**即使当前 40 分钟实时弹幕未开启或已过期，学生课前、课后仍可随时浏览本课件的历史提问，并点击点赞（“我也有这个疑问”）**，实时累加同问计数；支持取消点赞（一人一票）。
  - **范围隔离与治理**：学生端默认展示本班历史提问（可选切换查看“本课件全部精选/置顶提问”，跨班展示时隐藏具体姓名、脱敏显示为“同学”以保护隐私）；教师端支持按班级或全部班级查看，并可对任意历史问题执行**置顶（设为常见疑问）**、**软删除（清理课堂灌水）**或添加**简短教师解答备注**（`teacher_reply`），让高频疑问沉淀为课件常驻 FAQ。
- **发言秩序保护**：
  - 实时弹幕内实名显示（`真实姓名：内容`），单条限 40 字，学生发送冷却间隔 15 秒。

### 3. 平板硬件与安全沙箱基线（联想 Tab M9 实测）
依据 `docs/平板性能测试结果-20261118.md`（Android 11 WebView / Chrome 106，内嵌播放区域有效 CSS 视口 `1016 × 563`，4 GB 内存，平均 `33.6 fps`，p95 帧时间 `48.2 ms`）：
- **通信选型**：`nginx/edusimu.conf` 当前未配置 WebSocket Upgrade；课堂弹幕属于低频文本消息，采用**按会话状态自适应频率的增量短轮询**（会话开启时 3.5 秒，关闭时 15 秒检查开关，页面不可见 `document.hidden` 时暂停），断网恢复天然不丢消息。
- **零阻塞弹幕渲染**：弹幕层挂在 `AnimationPlayer.vue` 的 `ref="playerContainer"` 内部、`iframe` 之上（`pointer-events: none`），普通/沉浸/全屏模式一致可用；轨道限制在顶部下方 `64px ~ 170px` 区域的 **2~3 条轨道**、同屏上限 **6 条**，纯 CSS `@keyframes` + `transform: translate3d` 驱动并在动画结束立即回收 DOM；禁用 `backdrop-filter` 与模糊阴影；关闭态 `v-if` 卸载弹幕层。
- **防软键盘挤压**：提问浮层按需打开，内置快捷提问胶囊，发送后主动 `blur()` 收起软键盘。
- **安全沙箱红线**：仍严禁向隔离课件（`edusimu-isolated-tongjiang-v1`）发送 `EDUSIMU_CONTEXT` 或任何登录 `token`；所有来自 iframe 的消息必须经 `frontend/src/utils/coursewareBridge.js` 校验来源与结构化白名单后，再由外层播放器代为请求后端。

## 二、《EduSimu 课件题目规范 v1》

凡希望平台**自动识别题目、开启作答统计并留存教师报表**的新建或改版 HTML 课件，须同时满足以下两项轻量要求（共约 15 行声明与调用，已适配 AI 生成）：

### 1. 静态声明：内嵌标准题目清单（供上传自动认题）
在 HTML 内置一个 `<script type="application/json" id="edusimu-quiz-manifest">` 标签：

```html
<script type="application/json" id="edusimu-quiz-manifest">
{
  "version": 1,
  "questions": [
    {
      "id": "q1",
      "title": "第1题：入射光频率增大时遏止电压的变化",
      "type": "choice",
      "options": ["A. 增大", "B. 减小", "C. 不变", "D. 无法确定"],
      "answer": "A",
      "maxScore": 1
    },
    {
      "id": "q2-1",
      "title": "第2题(1)：逐差法计算小车加速度",
      "type": "numeric",
      "answer": "2.40",
      "maxScore": 2
    }
  ]
}
</script>
```

**字段约束**：
- `version`：整数，固定为 `1`。
- `questions`：非空数组，最多 200 题，总 JSON 体积 ≤ 64 KB；每个元素包含：
  - `id`（必填，字符串 ≤ 80 字符，同课件内唯一，如 `q1`、`m01-q2-p1`）；
  - `title`（必填，字符串 ≤ 200 字符，用于教师端统计表头展示）；
  - `type`（必填，枚举：`choice | multi | numeric | fill | expr | plot | open`）；
  - `options`（可选，字符串数组，单/多选题用于选项分布统计）；
  - `answer`（可选，参考答案展示文本，长度 ≤ 200 字符）；
  - `maxScore`（可选，整数 ≥ 1，默认 `1`）。

### 2. 运行时上报：判分/提交时发送 `postMessage`（供自动记数）
课件自身保持离线独立运行（无需 `fetch`、无需引入外部脚本、不影响本地双击运行），在学生每次提交/判分时向父窗口发送一条结构化消息：

```js
if (window.parent && window.parent !== window) {
  window.parent.postMessage({
    type: 'EDUSIMU_QUIZ_SUBMIT',
    version: 1,
    questionId: 'q1',          // 必须与 manifest 中某题的 id 一致
    answer: 'B',               // 学生实际作答文本/选项（序列化后 <= 1024 字节）
    isCorrect: false,          // boolean：是否判对
    score: 0,                  // 可选整数，默认 isCorrect ? maxScore : 0
    mistakeTag: '方向判断反了' // 可选错因短标签（<= 50 字符）
  }, '*');
}
```

### 3. 平台上传校验器（`validate_courseware`）三态准入判定

| 上传 HTML 检测结果 | 平台判定 (`has_quiz`) | 后台与前台行为 |
| --- | --- | --- |
| **无** `#edusimu-quiz-manifest` | `false`（普通动画） | 正常通过校验；仅启用平台弹幕，不展示作答统计入口 |
| **有**合法 `#edusimu-quiz-manifest` **且**源码含 `EDUSIMU_QUIZ_SUBMIT` 上报调用 | `true`（规范带题课件） | 自动解析题单存入 `animations.quiz_manifest`；校验详情提示“已识别 N 道标准题目，作答收集已启用”；首页展示 `含随堂练` 标签；播放页启用教师作答统计 |
| **有** `#edusimu-quiz-manifest` 但 JSON 格式错误、字段缺失或缺少 `EDUSIMU_QUIZ_SUBMIT` 调用 | `false`（规范不完整） | **不阻断普通播放校验通过**，但在校验提醒项中精准给出缺失原因与“一键 AI 修复规范 Prompt”，告知暂不开启作答记录 |

*(指南协同：将上述规范与可直接复制的 AI Prompt 模板同步嵌入 `backend/app/routers/animations.py` 的 `COMMON_AI_CONSTRAINTS` / `build_issue_prompts` 以及 `frontend/src/views/AnimationManage.vue` 的“课件设计指南”弹窗。)*

## 三、分阶段实施计划（弹幕优先，3 阶段落地）

### 阶段一（优先落地）：纯平台课堂弹幕与历史提问墙全栈实现

**目标**：在不修改任何现有课件的前提下，为全平台所有已发布课件上线“默认关闭、教师按班开启、40 分钟自动关闭”的实时弹幕，以及**常驻保留、课前课后随时可浏览并点赞“我也有这个疑问”的课件历史弹幕区（提问墙）**。

**涉及文件**：
- `backend/app/models.py`
- `backend/app/init_db.py`
- `backend/app/schemas.py`
- `backend/app/routers/classroom.py`（新建）
- `backend/app/main.py`
- `frontend/src/views/AnimationPlayer.vue`
- （可选组件拆分）`frontend/src/components/ClassroomDanmakuOverlay.vue`、`frontend/src/components/ClassroomQuestionPanel.vue`

**后端任务**：
1. 在 `backend/app/models.py` 新增三张表：
   - `DanmakuSession`：`id`、`animation_id`、`class_name`、`opened_by`、`opened_at`、`expires_at`、`closed_early`；
   - `DanmakuMessage`：`id`、`session_id`、`animation_id`、`class_name`、`user_id`、`content`、`upvote_count`、`is_pinned`、`is_deleted`、`teacher_reply`（`Text`，可空，教师简短解答备注）、`replied_at`（`DateTime(timezone=True)`，可空）、`created_at`（建立 `(animation_id, class_name, session_id, id)` 与 `(animation_id, is_deleted, is_pinned, upvote_count)` 复合索引，兼顾当堂轮询与历史提问墙按置顶/热度排序分页）；
   - `DanmakuUpvote`：`id`、`message_id`、`user_id`、`created_at`，唯一约束 `(message_id, user_id)`（支持对历史与当堂问题的长期点赞/取消点赞）。
2. 在 `backend/app/routers/classroom.py` 实现并注册路由（并在 `main.py` 挂载）：
   - `GET /api/classroom/animations/{animation_id}/danmaku/state?class_name=&after_id=0`：仅服务当堂 40 分钟实时会话，返回会话是否有效（`not closed_early and now < expires_at`）、`session_id`、`remaining_seconds`（剩余秒数，最大 2400）、当前会话内增量弹幕与当前用户已点赞消息 ID 集合。
   - `GET /api/classroom/animations/{animation_id}/danmaku/history?scope=class|all&sort=hot|latest&page=1&page_size=20`：常驻历史提问墙接口（**不受 40 分钟开关限制**），过滤 `is_deleted=True`，按 `sort=hot`（置顶优先 → 点赞数降序 → 最新）或 `sort=latest` 分页返回问题列表（含 `upvote_count`、`upvoted_by_me`、`is_pinned`、`teacher_reply`、`replied_at`、提问时间与展示名称）；学生查看 `scope=all` 时仅展示置顶/精选跨班问题或对发帖人做“同学”脱敏处理；教师/管理员支持筛选指定班级或全部班级。
   - `POST /api/classroom/animations/{animation_id}/danmaku/session`（仅 `teacher` / `admin`，复用 `teacher_classes` 校验班级归属）：`action="open"` 时先关闭同课件同班尚未结束的旧会话并新建一条 `expires_at = now + 40min` 的新会话；`action="close"` 时置 `closed_early = True`。
   - `POST /api/classroom/animations/{animation_id}/danmaku/messages`：校验会话处于有效 40 分钟窗口内、正文非空且 ≤ 40 字、学生端 15 秒发送冷却限制；保存实名信息，写入当前会话（自动沉淀进历史提问墙）。
   - `POST /api/classroom/animations/{animation_id}/danmaku/messages/{message_id}/upvote`：**不受 40 分钟会话开关限制**，对当前用户有权查看且未删除的任意当堂或历史问题执行点赞/取消点赞（toggle），表示“我也有这个疑问”，原子更新 `upvote_count` 并返回最新状态与计数。
   - `PATCH /api/classroom/animations/{animation_id}/danmaku/messages/{message_id}`（仅 `teacher` / `admin`）：置顶重点问题（设为常见疑问）、软删除课堂灌水，或写入/更新 `teacher_reply` 简短答疑。

**前端任务（`AnimationPlayer.vue`）**：
1. **学生端实时弹幕与快捷提问**：
   - 进入播放页静默请求一次 `/danmaku/state`；若 `is_open === false`，仅每 15 秒探测一次会话是否开启，页面零实时飘屏与零发言输入框。
   - 当检测到教师开启弹幕后：顶栏（及沉浸模式下悬浮控制区）显示 **`[弹幕: 开/关]`** 与 **`[课堂提问]`** 按钮；轮询切换为 3.5 秒增量拉取，本地同步运行 `remaining_seconds` 倒计时，到时自动收起实时飘屏并保留历史沉淀记录。
   - 弹幕轨道限定在播放器顶部下缘 `64px ~ 170px` 的 3 条轨道、同屏最多 6 条，CSS `@keyframes` + `translate3d` 驱动并在结束后回收节点。
   - `[课堂提问]` 浮层展示当堂问题清单（可点赞同问）、单行输入框和 4 个快捷胶囊（`这里没看懂`、`实验现象不明显`、`数据算不对`、`求讲这道题`），发送后 `blur()` 自动收起平板软键盘。
2. **课件历史弹幕区 / 提问墙（常驻，课前课后均可用）**：
   - **普通模式**：在播放页右侧栏（紧邻“动画信息”与“评分与评论”）常驻展示**“课件历史弹幕区 / 提问墙”**卡片，按需拉取 `/danmaku/history`，支持切换 `最热(同问最多)` / `最新` 与范围（本班提问 / 全校精选置顶）；每条问题带醒目的 **`我也有这个疑问 (N)`** 点赞按钮，**未开实时弹幕时也可随时浏览和点赞**；存在 `teacher_reply` 时在问题下方轻量展示教师解答。
   - **沉浸模式**：未开实时弹幕时保持克制，仅在悬浮操作区提供轻量 **`[历史提问 (N)]`** 入口按需展开抽屉查看与点赞，不常驻占用 `1016 × 563` 视口。
3. **教师端课堂控制与提问治理**：
   - 播放页顶栏提供班级选择器与 **`[开启本班弹幕 (40min)]`** / **`[弹幕开启中 MM:SS · 关闭]`** 按钮；
   - 在“课堂提问墙”抽屉与右侧历史弹幕区统一支持：筛选本班/全部班级、一键置顶常见问题、填写/编辑简短解答备注、删除灌水或不当弹幕。

### 阶段二：《EduSimu 课件题目规范 v1》平台识别、作答收集与教师统计

**目标**：让任何遵循规范 v1 的 HTML 课件上传即可自动建档，学生在播放页做题自动落库，教师在播放页直接查看按题与按人统计。

**涉及文件**：
- `backend/app/models.py`、`backend/app/init_db.py`、`backend/app/schemas.py`
- `backend/app/routers/animations.py`、`backend/app/routers/classroom.py`
- `frontend/src/utils/coursewareBridge.js`、`frontend/tests/coursewareBridge.test.mjs`
- `frontend/src/views/AnimationPlayer.vue`
- `frontend/src/views/Home.vue`、`frontend/src/views/AnimationManage.vue`

**后端任务**：
1. **`Animation` 表扩展与自动迁移**：
   - 新增 `has_quiz = Column(Boolean, default=False, nullable=False, index=True)` 与 `quiz_manifest = Column(Text)`（存储解析校验后的标准题单 JSON）。
   - 在 `init_db.py` 的 `ensure_animation_columns` 补齐两列 `ALTER TABLE` 兼容迁移。
2. **新增作答记录表 `CoursewareQuizAttempt`**：
   - 核心字段：`id`、`animation_id`、`user_id`、`question_key`、`question_title`、`question_type`、`is_correct`、`first_is_correct`（首次判分结果，重做不覆盖）、`score`、`max_score`、`student_answer`、`expected_answer`、`mistake_tag`、`attempt_count`、`first_submitted_at`、`updated_at`。
   - 唯一约束：`UniqueConstraint("user_id", "animation_id", "question_key", name="uq_quiz_attempt_user_anim_q")`。
