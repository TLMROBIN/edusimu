# 动画批量导入工具使用说明

## 功能说明

该工具用于将现有的HTML动画文件批量导入到教育动画展示系统中。

## 使用方法

### 方式一：从目录批量导入

**基本用法：**

```bash
cd /var/www/edusimu/backend
source venv/bin/activate
python ../scripts/import_animations.py --mode directory --path /path/to/animations
```

**示例：**

假设你的动画文件存储在 `/home/user/animations/` 目录下：

```bash
python ../scripts/import_animations.py --mode directory --path /home/user/animations/
```

**目录结构建议：**

```
animations/
├── physics/
│   ├── newton_law.html
│   └── mechanics.html
├── chemistry/
│   ├── reaction.html
│   └── molecular.html
└── biology/
    ├── cell.html
    └── dna.html
```

工具会自动识别学科分类（根据子目录名称），并将动画导入到相应学科。

### 方式二：从CSV文件导入

**CSV文件格式：**

```csv
file,title,subject,description,grade_level,keywords,is_published
/path/to/newton.html,牛顿第二定律,physics,演示力与加速度关系,高一,力学,牛顿定律,true
/path/to/cell.html,细胞结构,biology,动植物细胞结构对比,高二,细胞,生物膜,true
```

**使用方法：**

```bash
python ../scripts/import_animations.py --mode csv --path /path/to/animations.csv
```

**CSV列说明：**

| 列名 | 必填 | 说明 | 示例 |
|------|------|------|------|
| file | 是 | HTML文件路径（绝对路径） | /home/user/anim.html |
| title | 是 | 动画标题 | 牛顿第二定律 |
| subject | 是 | 学科名称（英文） | physics |
| description | 否 | 动画描述 | 演示力与加速度关系 |
| grade_level | 否 | 适用年级 | 高一 |
| keywords | 否 | 关键词（逗号分隔） | 力学,牛顿定律 |
| is_published | 否 | 是否发布 | true 或 false |

### 完整参数说明

```bash
python ../scripts/import_animations.py [选项]

必需参数：
  --mode {directory,csv}    导入模式
  --path PATH              目录路径或CSV文件路径

可选参数：
  --creator ID             创建者用户ID（默认使用管理员）
  --subject SUBJECT        默认学科分类（默认：physics）
  --published              导入后是否发布（默认：是）
  --create-teacher         创建示例教师账号
```

## 使用示例

### 示例1：导入物理学科动画

```bash
# 创建教师账号并导入
python ../scripts/import_animations.py \
  --mode directory \
  --path /home/user/physics_animations/ \
  --create-teacher \
  --subject physics
```

### 示例2：导入所有学科动画

```bash
# 假设动画按学科分类存储在子目录中
python ../scripts/import_animations.py \
  --mode directory \
  --path /home/user/all_animations/
```

### 示例3：从CSV文件导入

```bash
# 准备CSV文件 animations.csv
# 内容如下：
# file,title,subject,description,grade_level,keywords,is_published
# /home/physics/newton.html,牛顿第二定律,physics,力与加速度,高一,力学,true

python ../scripts/import_animations.py \
  --mode csv \
  --path animations.csv
```

### 示例4：指定创建者

```bash
# 使用教师ID=2作为创建者
python ../scripts/import_animations.py \
  --mode directory \
  --path /home/user/animations/ \
  --creator 2
```

## 注意事项

1. **文件格式**：仅支持 `.html` 文件
2. **文件大小**：单文件最大50MB
3. **路径要求**：
   - 目录模式：确保目录路径正确且有读取权限
   - CSV模式：确保文件路径为绝对路径
4. **学科识别**：
   - 目录模式会根据子目录名自动识别学科
   - 如果无法识别，使用默认学科（physics）
5. **重复导入**：相同文件多次导入会创建多个动画记录
6. **创建者权限**：创建者需要有教师或管理员权限

## 导入后操作

导入完成后，建议：

1. 登录管理后台检查导入结果
2. 编辑动画元数据（标题、描述等）
3. 确认发布状态
4. 测试动画播放是否正常

## 故障排查

### 问题1：找不到文件

**错误信息：** `文件不存在: /path/to/file.html`

**解决方法：**
- 检查文件路径是否正确
- 使用绝对路径
- 检查文件权限

### 问题2：学科不存在

**错误信息：** `学科 'xxx' 不存在`

**解决方法：**
- 使用正确的学科英文名称
- 检查数据库中是否有该学科

### 问题3：权限不足

**错误信息：** `Permission denied`

**解决方法：**
- 检查文件读取权限
- 使用正确的用户运行脚本

### 问题4：数据库连接失败

**错误信息：** `无法连接数据库`

**解决方法：**
- 确认PostgreSQL服务正在运行
- 检查数据库连接配置
- 确认数据库用户权限

## 批量导入建议

### 新学期准备流程

1. **准备动画文件**
   - 按学科分类存放
   - 确保文件名规范
   - 检查文件完整性

2. **准备元数据**
   - 创建CSV文件
   - 填写标题、描述等信息
   - 确定年级和关键词

3. **执行导入**
   - 先小批量测试
   - 检查导入结果
   - 大批量导入

4. **验证和发布**
   - 登录系统检查
   - 测试播放
   - 调整元数据
   - 发布给学生

### 文件命名建议

推荐格式：`学科_年级_主题_版本.html`

示例：
- `physics_g11_newton-law_v1.html`
- `chemistry_g10_reaction_v2.html`
- `biology_g11_cell-structure_v1.html`
