# 地理教材目录来源

本次系统内 `geography` 学科目录，依据国家中小学智慧教育平台公开教材资源整理。

整理方法：

- 先读取教材明细 JSON，确认教材身份与资源 ID。
- 再读取教材公开预览图的目录页，对目录进行 OCR 和人工校对。
- 最终仅录入书内正式章节与节标题，不录入“问题研究”“附录”等非节次节点。
