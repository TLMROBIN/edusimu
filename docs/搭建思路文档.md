# 教育动画网站搭建思路文档

## 项目概述

**项目名称：** 教学HTML动画展示系统（EduSimu）  
**目标：** 构建一个局域网网站，用于承载教学用的HTML动画，支持学生交互和学习记录追踪。  
**部署环境：** Ubuntu服务器，32GB内存，4TB存储，局域网访问（IP地址方式）  
**并发需求：** 支持上百人同时访问，总用户上千人  

---

## 技术决策

### 数据库选择：PostgreSQL
**原因：** 
- 上百人同时并发 + 上千总用户，SQLite在高并发写入时会产生锁冲突
- PostgreSQL优势：开源免费、支持高并发、32GB内存下性能优秀
- 存储空间评估：
  - 用户数据：< 10MB
  - 动画元数据：< 50MB
  - HTML动画文件（假设1000个，每个5-10MB）≈ 5-10GB
  - 数据库本身 < 100MB
  - **总计约10GB，远小于4TB**

### 技术架构
```
[学生/教师平板] 
       ↓
[Nginx 反向代理] (处理静态文件 + 转发API请求)
       ↓
[FastAPI 后端服务] ← [PostgreSQL 数据库]
       ↓
[管理员后台界面] (教师专用)
```

### 技术栈
- **前端：** Vue 3 + Vite + Element Plus
- **后端：** Python FastAPI + SQLAlchemy
- **数据库：** PostgreSQL 15
- **Web服务器：** Nginx
- **进程管理：** Systemd + Uvicorn

## 功能需求

### 用户认证
- **方式：** 教师批量创建学生账号
- **角色：** 学生(student)、教师(teacher)、管理员(admin)
- **登录：** 用户名 + 密码，JWT Token认证

### 动画管理
- **上传方式：** Web界面上传（单个文件限制50MB）
- **学科分类：** 语文、数学、英语、物理、化学、生物、地理、政治、历史
- **元数据：** 标题、学科、年级、关键词、描述、缩略图
- **文件存储：** 按学科分类存储，命名规则：`{subject_id}/{timestamp}_{random_id}.html`

### 学习记录追踪
- **记录内容：**
  - 浏览时间
  - 观看时长
  - 交互次数（点击、拖拽等）
  - 测验成绩（如果动画包含测验）
- **通信方式：** 通过iframe嵌入HTML动画，使用`window.postMessage` API

## 数据库设计

### 表结构

#### 1. users（用户表）
```sql
- id: SERIAL PRIMARY KEY
- username: VARCHAR(50) UNIQUE NOT NULL
- password_hash: VARCHAR(255) NOT NULL
- role: VARCHAR(20) NOT NULL ('student', 'teacher', 'admin')
- real_name: VARCHAR(100)
- class_name: VARCHAR(50)
- is_active: BOOLEAN DEFAULT true
- created_at: TIMESTAMP
- updated_at: TIMESTAMP
```

#### 2. subjects（学科表）
```sql
- id: SERIAL PRIMARY KEY
- name: VARCHAR(50) UNIQUE NOT NULL
- display_name: VARCHAR(50)
- sort_order: INTEGER
```

#### 3. animations（动画表）
```sql
- id: SERIAL PRIMARY KEY
- title: VARCHAR(200) NOT NULL
- subject_id: INTEGER REFERENCES subjects(id)
- description: TEXT
- file_path: VARCHAR(500) NOT NULL
- thumbnail: VARCHAR(500)
- grade_level: VARCHAR(50)
- keywords: TEXT
- view_count: INTEGER DEFAULT 0
- created_by: INTEGER REFERENCES users(id)
- is_published: BOOLEAN DEFAULT false
- file_size: INTEGER
- created_at: TIMESTAMP
- updated_at: TIMESTAMP
```

#### 4. favorites（收藏表）
```sql
- id: SERIAL PRIMARY KEY
- user_id: INTEGER REFERENCES users(id)
- animation_id: INTEGER REFERENCES animations(id)
- created_at: TIMESTAMP
- UNIQUE(user_id, animation_id)
```

#### 5. ratings（评分评论表）
```sql
- id: SERIAL PRIMARY KEY
- user_id: INTEGER REFERENCES users(id)
- animation_id: INTEGER REFERENCES animations(id)
- score: INTEGER CHECK (score >= 1 AND score <= 5)
- comment: TEXT
- created_at: TIMESTAMP
- UNIQUE(user_id, animation_id)
```

#### 6. view_history（观看历史表）
```sql
- id: SERIAL PRIMARY KEY
- user_id: INTEGER REFERENCES users(id)
- animation_id: INTEGER REFERENCES animations(id)
- view_duration: INTEGER (秒)
- interaction_count: INTEGER DEFAULT 0
- quiz_score: INTEGER
- quiz_total: INTEGER
- viewed_at: TIMESTAMP
```

#### 7. animation_interactions（交互记录表）
```sql
- id: SERIAL PRIMARY KEY
- view_history_id: INTEGER REFERENCES view_history(id)
- interaction_type: VARCHAR(50) (click, drag, input等)
- interaction_data: JSONB
- timestamp: TIMESTAMP
```

## API设计

### 认证相关
- `POST /api/auth/login` - 用户登录
- `POST /api/auth/logout` - 用户登出
- `GET /api/auth/me` - 获取当前用户信息

### 用户管理
- `GET /api/users/` - 获取用户列表（教师/管理员）
- `POST /api/users/` - 创建用户（教师/管理员）
- `PUT /api/users/{id}` - 更新用户信息
- `DELETE /api/users/{id}` - 删除用户
- `POST /api/users/batch-create` - 批量创建学生（教师）

### 动画管理
- `GET /api/animations/` - 获取动画列表（支持分页、筛选）
- `GET /api/animations/{id}` - 获取动画详情
- `POST /api/animations/` - 上传动画（教师）
- `PUT /api/animations/{id}` - 更新动画信息
- `DELETE /api/animations/{id}` - 删除动画（教师）
- `GET /api/animations/subjects` - 获取学科列表
- `POST /api/animations/{id}/view` - 记录观看
- `POST /api/animations/{id}/interactions` - 记录交互

### 收藏与评分
- `GET /api/favorites/` - 获取用户收藏列表
- `POST /api/favorites/{animation_id}` - 收藏动画
- `DELETE /api/favorites/{animation_id}` - 取消收藏
- `POST /api/ratings/{animation_id}` - 提交评分评论
- `GET /api/ratings/{animation_id}` - 获取动画评分

### 学习统计（教师/管理员）
- `GET /api/stats/overview` - 总体统计
- `GET /api/stats/animations/{id}` - 单个动画统计
- `GET /api/stats/users/{id}` - 单个学生学习记录
- `GET /api/stats/classes/{class_name}` - 班级学习统计

### 管理后台
- `GET /api/admin/pending-animations` - 待审核动画
- `POST /api/admin/approve/{id}` - 审核通过
- `GET /api/admin/logs` - 系统日志

## 关键技术细节

### HTML动画交互追踪
通过iframe嵌入HTML动画，使用`window.postMessage` API进行通信。

动画文件需包含通信代码：
```html
<script>
function sendInteraction(type, data) {
    window.parent.postMessage({
        type: 'ANIMATION_INTERACTION',
        interactionType: type,
        data: data,
        timestamp: Date.now()
    }, '*');
}
</script>
```

### 文件上传与存储
- 文件命名：`{subject_id}/{timestamp}_{random_id}.html`
- 缩略图：自动生成或手动上传
- 文件大小限制：50MB
- 安全检查：上传时检查HTML是否包含恶意代码
