## 系统简介

教育动画展示系统是一个用于承载教学HTML动画的Web平台，支持：

- **多学科支持**：语文、数学、英语、物理、化学、生物、地理、政治、历史
- **交互式学习**：学生可以与动画进行交互，系统自动记录学习行为
- **学习追踪**：记录观看时长、交互次数、测验成绩等数据
- **评价系统**：支持收藏、评分、评论功能
- **管理后台**：教师可以管理学生账号和上传动画

## 快速开始

### 登录系统

1. 打开浏览器，访问系统地址（如：`http://192.168.1.100`）
2. 在登录页面输入用户名和密码
3. 点击"登录"按钮

**首次登录提示：**
- 学生账号由教师统一创建并分发
- 首次登录后建议修改密码（如有权限）

## 学生使用指南

### 1. 浏览动画

**首页功能：**
- 学科分类卡片：点击任意学科查看该学科的所有动画
- 搜索框：输入关键词搜索动画
- 热门动画：查看浏览量最高的动画
- 最新动画：查看最近上传的动画

**筛选动画：**
1. 点击学科卡片
2. 使用搜索框输入关键词
3. 按年级筛选（如果教师设置了年级信息）

### 2. 观看动画

**进入动画播放页：**
1. 在首页或动画列表中点击动画卡片
2. 系统自动加载动画内容

**播放页功能：**
- 动画展示区：主界面显示HTML动画
- 信息面板：查看动画描述、观看次数、评分
- 收藏按钮：将动画添加到收藏夹
- 评分评论：对动画进行评分和评论

**交互功能：**
- 部分动画支持交互操作（如点击、拖拽、输入等）
- 系统会自动记录你的交互行为
- 如果动画包含测验，提交后会自动记录成绩

**观看提示：**
- 观看时长会自动记录
- 退出页面时请点击"返回"或"退出"按钮，确保记录保存
- 如果动画未正常加载，请刷新页面

### 3. 收藏管理

**添加收藏：**
1. 在动画播放页点击"收藏"按钮
2. 提示"收藏成功"即已添加

**取消收藏：**
1. 在动画播放页点击"取消收藏"按钮
2. 提示"已取消收藏"即已移除

**查看收藏列表：**
1. 点击顶部导航栏的"个人中心"
2. 切换到"我的收藏"标签页

### 4. 评分与评论

**提交评分：**
1. 在动画播放页右侧找到"评分与评论"面板
2. 点击星星选择评分（1-5星）
3. 在文本框中输入评论内容
4. 点击"提交评分"按钮

**查看评分：**
- 动画信息面板会显示平均评分
- 评分提交后可以再次修改

### 5. 个人中心

**功能入口：**
点击顶部导航栏的"个人中心"按钮

**我的收藏：**
- 查看所有收藏的动画
- 点击动画卡片可以直接播放

**观看历史：**
- 查看观看过的动画记录
- 显示观看时长和交互次数
- 显示观看时间

## 教师使用指南

### 1. 教师后台概述

教师登录后，可以访问管理后台，功能包括：
- 数据统计：查看学生学习数据
- 动画管理：上传和管理动画
- 用户管理：创建和管理学生账号

**进入管理后台：**
点击顶部导航栏的"管理后台"按钮

### 2. 用户管理

#### 2.1 创建单个学生账号

1. 进入"用户管理"页面
2. 点击"创建用户"按钮
3. 填写学生信息：
   - 用户名（必填，建议使用学号）
   - 密码（必填，至少6位）
   - 姓名（建议填写真实姓名）
   - 班级（如：高一1班）
   - 角色（选择"学生"）
4. 点击"创建"按钮

#### 2.2 批量创建学生账号

**使用CSV格式批量创建：**

1. 进入"用户管理"页面
2. 点击"批量创建"按钮
3. 按照提示格式输入学生信息，每行一个学生：
   ```
   用户名,密码,姓名,班级,角色
   student001,pass123,张三,高一1班,student
   student002,pass123,李四,高一1班,student
   student003,pass123,王五,高一2班,student
   ```
4. 点击"批量创建"按钮
5. 系统会显示创建结果（成功数量和错误信息）

**批量创建建议：**
- 使用Excel准备数据，复制粘贴到文本框
- 用户名避免重复
- 密码建议统一格式（如学号后6位）
- 创建后导出账号列表分发给学生

#### 2.3 管理学生账号

**查看学生列表：**
- 用户管理页面显示所有学生账号
- 可以按班级筛选

**禁用/启用账号：**
1. 找到目标学生
2. 点击"禁用"或"启用"按钮
3. 禁用后学生无法登录

**删除账号：**
1. 找到目标学生
2. 点击"删除"按钮
3. 确认删除（此操作不可恢复）

### 3. 动画管理

#### 3.1 上传动画

**准备动画文件：**
- 文件格式：仅支持HTML文件
- 文件大小：最大50MB
- 文件内容：完整的单文件HTML动画

**上传步骤：**
1. 进入"动画管理"页面
2. 点击"上传动画"按钮
3. 填写动画信息：
   - 标题：动画名称
   - 学科：选择所属学科
   - 描述：动画内容简介
   - 年级：适用年级（如：高一、高二）
   - 关键词：用逗号分隔（如：力学,牛顿定律）
   - 文件：选择HTML文件
   - 发布：勾选后学生可见
4. 点击"上传"按钮

#### 3.2 管理动画

**查看动画列表：**
- 显示所有上传的动画
- 可以看到观看次数和发布状态

**发布/下架动画：**
1. 找到目标动画
2. 点击"发布"或"下架"按钮
3. 发布后学生可见，下架后学生不可见

**删除动画：**
1. 找到目标动画
2. 点击"删除"按钮
3. 确认删除（此操作不可恢复）

### 4. 学习统计

**查看整体统计：**
- 学生总数
- 动画总数
- 总观看次数
- 总收藏数

**查看详细日志：**
- 最近活动：显示学生的观看记录
- 可以看到观看时长、交互次数等详细信息

## 管理员使用指南

### 1. 管理员权限

管理员拥有所有教师权限，额外包括：
- 管理教师账号
- 审核待发布动画
- 系统配置
- 查看系统日志

### 2. 账号管理

**创建教师账号：**
1. 进入"用户管理"页面
2. 点击"创建用户"
3. 角色选择"教师"
4. 填写其他信息并创建

**管理教师账号：**
- 可以禁用/启用教师账号
- 可以重置教师密码
- 可以删除教师账号

### 3. 动画审核

**查看待审核动画：**
1. 进入管理后台
2. 查看未发布的动画列表

**审核操作：**
- 发布：通过审核，学生可见
- 下架：拒绝审核，学生不可见

### 4. 系统维护

**查看系统日志：**
- 进入管理后台
- 查看最近活动日志
- 监控系统使用情况

**数据备份：**
定期备份数据库和上传文件（详见部署指南）

## 常见问题

### Q1: 忘记密码怎么办？

**学生：** 联系教师重置密码  
**教师：** 联系管理员重置密码  
**管理员：** 通过数据库或命令行工具重置

### Q2: 动画加载不出来？

**可能原因：**
1. 网络连接问题
2. 动画文件损坏
3. 浏览器兼容性问题

**解决方法：**
1. 刷新页面
2. 检查网络连接
3. 尝试使用Chrome或Firefox浏览器
4. 联系教师或管理员

### Q3: 为什么有些动画看不到？

**可能原因：**
1. 动画未发布（教师还未发布）
2. 账号被禁用
3. 权限不足

**解决方法：**
1. 确认动画已发布
2. 联系教师确认账号状态

### Q4: 如何查看我的学习记录？

1. 点击"个人中心"
2. 切换到"观看历史"标签页
3. 可以看到所有观看记录

### Q5: 动画可以下载吗？

当前系统仅支持在线观看，不支持下载。

### Q6: 支持哪些浏览器？

推荐使用：
- Google Chrome（推荐）
- Firefox
- Safari
- Edge

不支持 IE 浏览器。

### Q7: 移动端可以使用吗？

系统支持平板电脑和手机访问，但推荐使用平板电脑获得更好的体验。

### Q8: 动画支持全屏吗？

部分动画支持全屏，具体取决于动画本身的设计。

### Q9: 如何给教师反馈？

可以通过动画的评论功能反馈，或直接联系教师。

### Q10: 收藏数量有限制吗？

没有限制，可以收藏任意数量的动画。
