## 账号管理

### 创建学生账号

#### 方式一：单个创建

**适用场景：** 少量学生或临时添加

**操作步骤：**
1. 登录系统，点击"管理后台"
2. 进入"用户管理"页面
3. 点击"创建用户"按钮
4. 填写信息：
   - **用户名**：建议使用学号（如：2024001）
   - **密码**：建议统一格式（如：学号后6位）
   - **姓名**：学生真实姓名
   - **班级**：如"高一1班"
   - **角色**：选择"学生"
5. 点击"创建"

**示例：**
```
用户名：2024001
密码：24001
姓名：张三
班级：高一1班
角色：学生
```

#### 方式二：批量创建

**适用场景：** 新学期开始，批量创建班级学生

**准备工作：**
1. 在Excel中准备学生数据
2. 列顺序：用户名、密码、姓名、班级、角色
3. 确保用户名不重复

**操作步骤：**
1. 进入"用户管理"页面
2. 点击"批量创建"按钮
3. 按格式复制粘贴学生数据：
   ```
   2024001,pass001,张三,高一1班,student
   2024002,pass002,李四,高一1班,student
   2024003,pass003,王五,高一2班,student
   ```
4. 点击"批量创建"
5. 查看创建结果，记录失败的学生信息

**Excel模板示例：**

| 用户名 | 密码 | 姓名 | 班级 | 角色 |
|--------|------|------|------|------|
| 2024001 | pass001 | 张三 | 高一1班 | student |
| 2024002 | pass002 | 李四 | 高一1班 | student |
| 2024003 | pass003 | 王五 | 高一2班 | student |

**导出账号清单：**
1. 创建完成后，将账号信息导出
2. 打印分发给各班学生
3. 或通过班级群发送

### 管理学生账号

#### 重置密码

**场景：** 学生忘记密码

**方法一：记录密码后告知学生**
1. 暂时禁用账号
2. 创建新密码
3. 启用账号并告知学生新密码

**方法二：删除重建（谨慎操作）**
1. 记录学生的学习记录（如需保留）
2. 删除旧账号
3. 创建新账号并设置新密码

#### 禁用账号

**适用场景：**
- 学生违规使用
- 毕业或转学
- 临时停用

**操作步骤：**
1. 找到目标学生
2. 点击"禁用"按钮
3. 学生立即无法登录

#### 启用账号

**操作步骤：**
1. 找到被禁用的学生
2. 点击"启用"按钮
3. 学生可以重新登录

#### 删除账号

**注意：** 删除账号会清除该学生的所有数据，包括：
- 观看历史
- 收藏记录
- 评分记录
- 学习统计

**操作步骤：**
1. 确认是否需要备份学生数据
2. 找到目标学生
3. 点击"删除"按钮
4. 确认删除

## 动画管理

### 上传教学动画

#### 准备工作

**动画文件要求：**
- 格式：HTML文件（单文件）
- 大小：不超过50MB
- 内容：完整可运行的HTML动画

**元数据准备：**
- 标题：简洁明了
- 学科：选择正确的学科分类
- 描述：简要说明动画内容
- 年级：适用年级范围
- 关键词：方便学生搜索

#### 上传步骤

**方式一：通过Web界面上传**

1. 进入"动画管理"页面
2. 点击"上传动画"
3. 填写动画信息：
   ```
   标题：牛顿第二定律演示
   学科：物理
   描述：通过动画演示力、质量和加速度的关系
   年级：高一
   关键词：牛顿定律,力学,加速度
   文件：选择HTML文件
   发布：勾选
   ```
4. 点击"上传"

**方式二：批量导入**

**适用场景：** 大量动画文件需要导入

**操作步骤：**
1. 将动画文件按学科分类存放
2. 准备CSV格式的元数据文件
3. 使用批量导入脚本（见部署指南）
4. 上传完成后检查动画列表

#### 发布管理

**发布动画：**
1. 上传时勾选"发布"
2. 或上传后在列表中点击"发布"
3. 发布后学生可以查看

**下架动画：**
1. 找到目标动画
2. 点击"下架"按钮
3. 学生将无法查看（已收藏的也会失效）

**使用场景：**
- 发现动画内容错误
- 需要更新动画
- 暂时不让学生访问

#### 编辑动画信息

**可修改内容：**
- 标题
- 描述
- 年级
- 关键词
- 发布状态

**不可修改：**
- 文件内容（需重新上传）
- 学科分类

**修改步骤：**
1. 进入动画详情页
2. 点击"编辑"按钮
3. 修改需要更新的信息
4. 保存更改

#### 删除动画

**注意：** 删除动画会清除：
- 观看记录
- 收藏记录
- 评分记录

**操作步骤：**
1. 确认动画文件已备份（如需）
2. 找到目标动画
3. 点击"删除"按钮
4. 确认删除

### 动画制作建议

#### 文件结构

**推荐结构：**
```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>动画标题</title>
    <style>
        /* 样式代码 */
    </style>
</head>
<body>
    <!-- 动画内容 -->
    
    <script>
        // JavaScript代码
        
        // 交互事件通信（可选）
        function sendInteraction(type, data) {
            window.parent.postMessage({
                type: 'ANIMATION_INTERACTION',
                interactionType: type,
                data: data,
                timestamp: Date.now()
            }, '*');
        }
        
        // 示例：记录按钮点击
        document.getElementById('btn1').addEventListener('click', function() {
            sendInteraction('click', { element: 'btn1', action: 'simulate' });
        });
        
        // 示例：记录测验结果
        function submitQuiz(score, total) {
            sendInteraction('quiz', { score: score, total: total });
        }
    </script>
</body>
</html>
```

#### 最佳实践

1. **响应式设计**
   - 使用百分比或弹性布局
   - 适配不同屏幕尺寸
   - 支持触摸操作（移动端）

2. **性能优化**
   - 压缩图片资源
   - 使用CSS3动画代替JavaScript动画
   - 避免过大的文件

3. **交互设计**
   - 提供清晰的操作指引
   - 支持重置功能
   - 添加反馈提示

4. **教育价值**
   - 突出核心知识点
   - 提供参数调节功能
   - 支持多次尝试

## 学习监控

### 查看整体数据

**数据统计卡片：**
- 学生总数：当前系统中的学生数量
- 动画总数：已发布的教学动画数量
- 总观看次数：所有动画的观看次数总和
- 总收藏数：学生收藏动画的总次数

**进入方式：**
1. 登录后点击"管理后台"
2. 首页显示整体统计数据

### 查看班级学习情况

**操作步骤：**
1. 进入"用户管理"页面
2. 使用班级筛选功能
3. 查看该班级学生列表

**统计内容：**
- 学生观看记录
- 观看时长统计
- 交互次数统计
- 班级整体活跃度

### 查看单个学生学习记录

**操作步骤：**
1. 进入"用户管理"页面
2. 点击学生姓名或"查看详情"
3. 查看学习记录

**记录内容：**
- 观看过的动画列表
- 每次观看的时长
- 交互操作次数
- 测验成绩（如有）
- 收藏的动画
- 评分记录

### 查看动画使用情况

**操作步骤：**
1. 进入"动画管理"页面
2. 查看每个动画的观看次数
3. 点击动画查看详细统计

**统计内容：**
- 总观看次数
- 平均评分
- 收藏人数
- 观看学生列表
- 观看时长分布

### 导出学习数据

**数据导出：**
1. 进入相应统计页面
2. 点击"导出"按钮
3. 选择导出格式（Excel或CSV）
4. 下载文件

**使用场景：**
- 期末成绩统计
- 教学质量评估
- 学生学习报告

## 常见场景

### 场景一：新学期学生注册

**步骤：**
1. 准备学生名单Excel表格
2. 批量创建学生账号
3. 导出账号清单
4. 分发账号给学生
5. 指导学生首次登录

### 场景二：上传新教学动画

**步骤：**
1. 制作或获取HTML动画文件
2. 测试动画是否正常运行
3. 登录系统进入"动画管理"
4. 上传动画并填写元数据
5. 勾选"发布"让学生可见
6. 在课堂上引导学生使用

### 场景三：监控学生课后学习

**步骤：**
1. 布置学习任务（观看特定动画）
2. 次日登录管理后台
3. 查看动画观看统计
4. 查看学生观看记录
5. 识别未完成学习的学生
6. 课堂上提醒或单独沟通

### 场景四：处理学生反馈

**步骤：**
1. 学生反映某个动画有问题
2. 登录系统观看该动画
3. 确认问题类型：
   - 内容错误 → 下架并修正
   - 加载失败 → 检查文件或重新上传
   - 交互问题 → 检查动画代码
4. 解决问题后重新发布
5. 通知学生可以继续使用

### 场景五：学期末数据统计

**步骤：**
1. 进入管理后台
2. 查看整体统计数据
3. 导出学生观看记录
4. 导出动画使用统计
5. 在Excel中进行分析
6. 生成学习报告

## 最佳实践

### 1. 账号管理规范

**用户名命名规则：**
- 使用学号（推荐）
- 格式统一：年份+班级+序号（如：20240101）

**密码设置建议：**
- 初次使用简单密码（如：123456）
- 要求学生首次登录后修改密码
- 或使用学号后6位作为初始密码

**定期清理：**
- 学期末清理毕业学生账号
- 新学期清理不再使用的学生账号
- 保留学习数据备份

### 2. 动画发布流程

**发布前检查：**
1. 动画文件完整可运行
2. 元数据填写准确
3. 在不同设备测试兼容性
4. 确认学科分类正确

**分阶段发布：**
1. 先上传不发布
2. 课堂上演示使用方法
3. 课后发布让学生练习
4. 根据反馈优化

### 3. 教学结合建议

**课前预习：**
- 发布预习动画
- 查看学生预习数据
- 调整课堂教学重点

**课堂教学：**
- 演示核心概念动画
- 让学生现场操作
- 讨论观察结果

**课后复习：**
- 发布扩展动画
- 要求学生观看并评分
- 查看学习数据了解掌握情况

**作业布置：**
- 指定必看动画
- 要求提交观看时长截图
- 下次课检查完成情况

### 4. 数据利用策略

**定期查看数据：**
- 每周查看一次整体统计
- 关注异常数据（如观看时长过短）
- 识别高活跃度和低活跃度学生

**个性化辅导：**
- 根据观看记录识别学习困难学生
- 根据交互数据判断理解程度
- 针对性提供辅导

**教学改进：**
- 观看次数少的动画考虑优化
- 评分低的动画分析原因
- 学生反馈及时响应

### 5. 安全与隐私

**数据保护：**
- 定期备份数据库
- 不泄露学生账号信息
- 遵守学校数据管理规定

**权限管理：**
- 教师账号谨慎分发
- 及时禁用离职教师账号
- 定期审查账号权限

## 技术支持

### 常见问题

**Q: 上传动画失败？**
- 检查文件大小（最大50MB）
- 确认文件格式为HTML
- 检查网络连接

**Q: 学生无法登录？**
- 确认账号已创建
- 检查账号是否被禁用
- 确认密码正确

**Q: 动画加载慢？**
- 检查文件大小
- 优化动画资源
- 联系技术支持检查服务器

**Q: 数据统计不准确？**
- 刷新页面重试
- 检查数据筛选条件
- 联系管理员检查数据库

### 获取帮助

- 查看系统使用手册
- 联系学校技术支持
- 查看部署指南中的故障排查章节
