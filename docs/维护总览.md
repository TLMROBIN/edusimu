# EduSimu 维护总览

本文件用于快速交接：系统设计架构、主要功能、配置与数据位置，以及关键变更记录。用于新维护者快速上手，不替代更细的运维/部署/使用手册。

## 1. 系统设计架构

### 1.1 组件划分
- 前端：`frontend/`，Vue 3 + Element Plus，打包产物输出到 `frontend/dist/`。
- 后端：`backend/`，FastAPI + SQLAlchemy，提供课件/用户/统计等 API。
- 数据库：开发默认 SQLite；部署环境使用 PostgreSQL。
- 静态资源与课件：统一由后端 `uploads/` 持久化，并通过 Nginx 暴露。

### 1.2 运行与部署路径（生产）
- 后端部署目录：`/var/www/edusimu/backend`
- 前端部署目录：`/var/www/edusimu/frontend/dist`
- Nginx 配置：`/etc/nginx/sites-available/edusimu.conf`
- systemd 服务：`/etc/systemd/system/edusimu-backend.service`

### 1.3 访问与权限模型
- 角色：`student`（学生）、`teacher`（教师）、`admin`（管理员）
- 学生：只能浏览已发布课件
- 教师：可浏览所有已发布课件；只能管理自己上传的未发布课件
- 管理员：可管理全站用户、课件、教材目录与发布流程

## 2. 主要功能

- 课件上传与校验：支持 HTML / ZIP 课件包，自动校验触控/离线/资源依赖
- 教材目录绑定：课件必须绑定到最末级章节
- 课件审核发布：管理员发布，教师不可直接发布
- 课件浏览与播放：全站已发布课件可检索、筛选并播放
- 使用数据统计：教师看自己课件效果，管理员看全站
- 用户管理：管理员管理用户与角色

## 5. 运维与排查要点

- 服务状态：
  - `systemctl status edusimu-backend`
  - `journalctl -u edusimu-backend -n 100 --no-pager`
- 课件打不开：
  - 检查 `uploads/` 是否完整
  - 检查 Nginx `alias /var/www/edusimu/backend/uploads/`
- 课件列表为空：
  - 检查数据库是否指向正确实例（`DATABASE_URL`）
  - 检查权限过滤逻辑（`backend/app/routers/animations.py`）

## 7. 维护流程建议

- 代码改动：在 `edusimu/` 修改，前端需要 `npm run build`
- 同步到当前局域网远端服务器：优先执行 `./scripts/sync_remote_server.sh`
- 远端同步说明：见 `docs/远端同步.md`
- 部署后端：同步到 `/var/www/edusimu/backend` 并重启服务
- 部署前端：替换 `/var/www/edusimu/frontend/dist`
- 每次修改：在本文件补充记录（日期、改动点、影响范围）

## 9. 备份与恢复建议

- 数据库备份：
  - PostgreSQL：定期 `pg_dump -Fc edusimu > /path/to/backup/edusimu_YYYYMMDD.dump`
  - SQLite（开发）：直接备份 `backend/edusimu.db`
- 课件与缩略图备份：
  - `/var/www/edusimu/backend/uploads/`
- 恢复时要点：
  - 数据库与 `uploads/` 必须同时恢复，单独恢复任一会导致课件不可用

## 10. 应急排查流程（简要）

- 课件列表为空：
  - 检查 `DATABASE_URL` 是否指向正确实例
  - 检查后端权限过滤逻辑是否被改动
- 能打开页面但课件播放失败：
  - 检查 `uploads/` 是否完整
  - 检查 Nginx `alias` 路径
- 登录异常：
  - 检查后端日志 `journalctl -u edusimu-backend -n 100 --no-pager`
  - 检查数据库连接与账号是否可用
