# 教育动画展示系统 - 部署指南

## 系统要求

- Ubuntu 20.04/22.04 LTS
- 内存：至少 2GB RAM
- 存储：至少 10GB 可用空间
- CPU：建议 2核以上

## 快速部署（推荐）

### 1. 上传项目到服务器

将整个项目文件夹上传到服务器，例如：

```bash
scp -r edusimu/ user@your-server:/home/user/
```

### 2. 运行一键安装脚本

```bash
cd /home/user/edusimu
sudo ./scripts/install.sh
```

安装脚本会自动完成以下操作：
- 安装所有依赖软件（Python、Node.js、PostgreSQL、Nginx）
- 配置PostgreSQL数据库
- 安装Python和Node.js依赖
- 初始化数据库
- 构建前端应用
- 配置Nginx和Systemd服务
- 启动所有服务

### 3. 访问系统

安装完成后，通过浏览器访问：
```
http://服务器IP地址
```

**默认管理员账号：**
- 用户名：`admin`
- 密码：`admin123`

**重要：首次登录后请立即修改管理员密码！**

## 手动部署（高级用户）

### 1. 安装系统依赖

```bash
sudo apt-get update
sudo apt-get install -y python3 python3-pip python3-venv nodejs npm postgresql postgresql-contrib nginx
```

### 2. 配置PostgreSQL

```bash
sudo -u postgres psql
```

在PostgreSQL命令行中执行：

```sql
CREATE DATABASE edusimu;
CREATE USER edusimu WITH PASSWORD 'edusimu123';
GRANT ALL PRIVILEGES ON DATABASE edusimu TO edusimu;
ALTER USER edusimu CREATEDB;
\q
```

### 3. 配置后端

```bash
cd /path/to/edusimu/backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python init_db.py
```

### 4. 构建前端

```bash
cd /path/to/edusimu/frontend
npm install
npm run build
```

### 5. 配置Nginx

```bash
sudo cp nginx/edusimu.conf /etc/nginx/sites-available/
sudo ln -s /etc/nginx/sites-available/edusimu.conf /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

### 6. 配置Systemd服务

```bash
sudo cp nginx/edusimu-backend.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable edusimu-backend
sudo systemctl start edusimu-backend
```

## 服务管理

### 启动服务

```bash
sudo systemctl start edusimu-backend
sudo systemctl start nginx
```

或使用快捷脚本：

```bash
./scripts/start.sh
```

### 停止服务

```bash
sudo systemctl stop edusimu-backend
sudo systemctl stop nginx
```

或使用快捷脚本：

```bash
./scripts/stop.sh
```

### 重启服务

```bash
sudo systemctl restart edusimu-backend
sudo systemctl restart nginx
```

### 查看服务状态

```bash

sudo systemctl status nginx
```

### 恢复数据库

```bash
psql -U edusimu -h localhost edusimu < backup_20260304.sql
```

```bash

sudo -u postgres createdb -O edusimu edusimu
cd /path/to/edusimu/backend
source venv/bin/activate
python init_db.py
```

## 性能优化

### PostgreSQL优化

编辑 `/etc/postgresql/*/main/postgresql.conf`：

```ini
shared_buffers = 256MB
effective_cache_size = 1GB
maintenance_work_mem = 64MB
checkpoint_completion_target = 0.9
wal_buffers = 16MB
default_statistics_target = 100
random_page_cost = 1.1
effective_io_concurrency = 200
work_mem = 2621kB
min_wal_size = 1GB
max_wal_size = 4GB
max_worker_processes = 4
max_parallel_workers_per_gather = 2
max_parallel_workers = 4
max_parallel_maintenance_workers = 2
```

重启PostgreSQL：
```bash
sudo systemctl restart postgresql
```

### Nginx优化

编辑 `/etc/nginx/nginx.conf`：

```nginx
worker_processes auto;
worker_connections 2048;
multi_accept on;
use epoll;
```

重启Nginx：
```bash
sudo systemctl restart nginx
```

## 安全加固

### 1. 修改数据库密码

```bash
sudo -u postgres psql
ALTER USER edusimu WITH PASSWORD 'your_new_strong_password';
\q
```

然后更新 `backend/.env` 文件中的 `DATABASE_URL`。

### 2. 修改管理员密码

登录系统后，立即在管理后台修改管理员密码。

### 3. 配置防火墙

```bash
sudo ufw allow 80/tcp
sudo ufw allow 22/tcp
sudo ufw enable
```

### 4. 限制上传目录访问

确保上传目录权限正确：
```bash
sudo chown -R www-data:www-data /var/www/edusimu/backend/uploads
sudo chmod -R 755 /var/www/edusimu/backend/uploads
```

## 故障排查

### 后端无法启动

1. 检查数据库连接：
```bash
psql -U edusimu -h localhost -d edusimu
```

2. 检查端口占用：
```bash
sudo netstat -tlnp | grep 8000
```

3. 查看详细日志：
```bash
sudo journalctl -u edusimu-backend -n 100 --no-pager
```

### 前端无法访问

1. 检查Nginx配置：
```bash
sudo nginx -t
```

2. 检查Nginx日志：
```bash
sudo tail -f /var/log/nginx/error.log
```

3. 检查文件权限：
```bash
ls -la /var/www/edusimu/frontend/dist
```

### 数据库连接失败

1. 检查PostgreSQL服务：
```bash
sudo systemctl status postgresql
```

2. 检查数据库用户和权限：
```bash
sudo -u postgres psql
\du edusimu
\l edusimu
```

3. 检查连接字符串：
确认 `backend/.env` 中的 `DATABASE_URL` 正确。

## 常见问题

### Q: 上传文件大小限制？

A: 默认限制为50MB。可在 `backend/.env` 中修改 `MAX_FILE_SIZE` 参数（单位：字节），并同步修改 Nginx 配置中的 `client_max_body_size`。

### Q: 如何修改监听端口？

A: 修改 `/etc/nginx/sites-available/edusimu.conf` 中的 `listen` 指令，然后重启Nginx。

### Q: 支持HTTPS吗？

A: 当前配置仅支持HTTP。如需HTTPS，可使用Let's Encrypt：
```bash
sudo apt-get install certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com
```

### Q: 如何添加新的学科分类？

A: 登录管理员后台，通过API或数据库直接插入 `subjects` 表。
